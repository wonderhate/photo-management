# Wonder 个人网站改进

依据《Lumina-30天低预算增长方案-2026-10-17》筛选网站内改动。所有者明确的目标是小范围推广个人、认识更多人，并积累可展示的项目经历；摄影作品仍为首页主角。公开身份使用 Wonder，不编造职业或学历；“计算机专业”按所有者要求仅在 Windows 下载页 QQ 上方小字展示。

## 页面与内容

- 首页补充个人介绍、项目体验入口、支持环境提醒和 QQ 交流区；保留作品选片、轮播、搜索、灯箱与页底光影集入口。没有影集时隐藏首页空影集区和主导航空入口，旧链接保留。
- `/about/` 和 `/en/about/` 介绍 Wonder、摄影与个人项目，提供 QQ 复制及交流指引。
- `/lumina/` 和 `/en/lumina/` 提供真实功能、三步上手、项目实践、AI 辅助说明及数据边界。未宣称所有格式可用、全部离线、无限免费或虚构使用人数。
- `/en/` 提供稳定英文作品首页。语言切换保留当前作品视图；普通本地应用及 Windows 下载入口继续可用。
- 静态说明页无 JavaScript 也可读；首页初始 HTML 包含个人介绍和最多 6 张已选精选作品的回退展示。交互图库仍为原 React 应用，并非整站服务端渲染。
- 补 canonical、语言互链、Open Graph / Twitter、robots.txt 和 sitemap.xml。分享图仅使用已明确发布的照片或现有图标，不扫描其他本地照片。

## 边界与维护

仅在独立网页版仓库修改，未修改原 Windows 桌面工程。图库数据结构、编辑算法和原片均未改动。Windows 文件保持 1.0 名称、2.6.1 内容，HTTPS 直链与 GitHub 备用下载保留。

照片与影集仍在本机作者页更新；介绍文案在 public-profile.ts 和 public-pages.mjs 维护。公开名字与 QQ 沿用 windows-release.json；没有新增公共上传、编辑、留言、账号或个人数据收集接口。站点访客不能通过新页面改动作品。

没有自动发布社区帖子、联系他人、购买广告或提交站长平台。基础搜索与分享配置不等于已被搜索引擎收录，也没有伪造推广数据。

打包继续使用明确文件允许列表；新增 HTML 仅允许约定的五个子页面，其他 en/about/lumina 目录文件仍被拒绝。作者代码、私有草稿、Token、日志与测试截图不进入网站包或 Git。
