# 本机作者发布与部署记录

日期：2026-10-17。网页版版本：2.6.1。开发仓库：独立的 `photo_collection_web`；原桌面仓库未被修改。

## 使用

双击仓库根目录的 `打开作品发布.cmd`，或运行 `npm run author`。程序在 Edge 打开仅监听本机 4178 端口的作者页，完整地址带服务启动时生成的随机会话码；重复双击会核对并打开已运行的同一作者页。无需先导入私人图库，可以直接选择多张 JPEG、PNG、WebP，填写公开文字并排序；也可分别上传到首页轮播、精选作品或指定影集。轮播最多 6 张，精选最多 12 张。

“保存本机草稿”仅保存到 `.local-notes/publisher/content`；“生成预览与上传包”构建本机预览及 `releases/Lumina-Web-时间/browser-static.zip`；“发布到正式网站”才上传并更新线上网站。构建只复制 manifest 引用的展示 JPEG，原文件名、EXIF、GPS 和本机路径不进入展示数据。原片只读。

EdgeOne Makers 的项目固定为 `makers-o7xx3x5jqy77`，名称 `photomanagement`，网站 `https://photomanagement.online/`。使用该账户的 Makers API Token，与照片 AI Key 无关。发布前读取项目核对 ID 和名称，不创建新项目、不改 DNS，也不操作新加坡 AI 中转。

Token 可仅保留服务会话内，也可使用 Windows DPAPI 加密保存在 `.local-notes/publisher/edgeone-token.dpapi`，与当前 Windows 用户绑定。只在项目校验通过后标记为可用；加密保存失败时保留本次会话使用能力并明确提示，避免把持久化故障当作 Token 无效。发布凭据、作者会话码和作者代码均不进入网站包或 Git。

## 访问边界

公开包无作者页面、发布组件或写入作品的 API；访客使用光影集时仅管理自行授权的本地文件。修改浏览器中的显示或下载并修改副本不会改变网站的部署。更新正式作品需要所有者本机服务及其托管凭据。

本机写入接口要求随机会话码、精确的 `127.0.0.1:端口` Host、同源 Origin，并拒绝跨站请求。请勿将本机发布服务代理到公网。关闭进程只关闭作者入口，线上静态网站继续运行。

## 回退及异常

每次生成的 ZIP 和文件 SHA-256 清单保留在 `releases/`，不覆盖旧包。可在 EdgeOne 控制台选择历史部署回退，也可重新上传保留的 ZIP。提交后部署编号记录在 `.local-notes/publisher/last-deployment.json`，正式域名内容核对成功后另存 `last-success.json`。超时仅表示本机等待结束，云端可能继续部署；先检查该部署编号，避免重复提交。

2026-10-17 修复了 PowerShell 7 的 `PSModulePath` 被 Windows PowerShell 继承后，错误加载不兼容安全模块而导致的凭据加密失败。现在显式导入 Windows PowerShell 自己的系统安全模块；回归覆盖不兼容模块路径下的加密保存与重新读取。

同日修复重复运行 `打开作品发布.cmd` 时的 `EADDRINUSE`。本机 `.runtime/publisher-instance.json` 保存会话记录，启动器通过随机会话码、程序标识和仓库标识核对已有服务后复用；失效记录自动恢复，其他程序占用端口时给出提示而不关闭该程序。覆盖重复启动、重启恢复和无关端口占用，前端逻辑测试共 15 项通过；实际重复运行 `npm run author` 返回成功并打开同一地址。

## 展示页的精选作品与影集上传

作者页新增独立的“首页轮播”“精选作品”和“影集”区域，可分别直接上传多张照片，也可选入已有照片。支持轮播及精选的排序、移出；影集的新建、改名、介绍、排序、照片上传及选入、照片顺序调整和删除影集。影集首张为封面；删除影集或移出策展区域不删除公开照片，更不会操作原片。

公开清单新增可选 `coverIds`（最多 6 个有效且不重复的照片 ID）。新版按明确的轮播与精选顺序渲染，允许明确清空精选；旧清单未包含该字段时保持原有回退方式。全部作品、精选与影集共同引用同一份去元数据的展示副本，无需复制同一张图。
