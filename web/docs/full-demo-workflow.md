# 完整本机体验流程

本机体验入口为 `/?local=1&demo=1#/`。进入后加载网站当前示例并打开完整光影暗房；访客也可以换用自己的本机照片。作者可在自己电脑的专用作品发布页更换共享示例，重新发布后所有访客使用新图。未配置网站示例时，采用明确标记的程序绘制插画。公开展示页保留的三张示意图仍是这张插画的真实渲染结果，不作为摄影作品或真实照片处理质量的证明。

## 作者更换共享示例

打开本机专用作品发布页，在“体验示例照片”区域点击“选择体验示例照片”。支持 JPEG、PNG 和 WebP；发布页生成长边最多 2560 像素的 JPEG 展示副本，移除 EXIF、GPS 及原文件名。该照片独立于摄影作品清单，不改变轮播、精选或影集。选择后先“生成预览与上传包”，确认后“发布到正式网站”；访客此后默认使用新图。点击“恢复内置示例”并重新发布，可改回程序绘制插画。

## 三步创作

1. **光影暗房**复用实际编辑器，保留参考图仿色、曝光与白平衡、曲线与 HSL、LUT、构图、图层、文字、细节、原图对比及撤销／重做。用户可以重新打开本机照片；进入下一步时保存本次编辑参数，并渲染独立副本交给水印工坊。
2. **水印工坊**复用实际本地工坊，保留信息条、沉浸光感、相框模板和图层、Logo、可见拍摄信息、署名、预览及导出参数。水印体验不提供云端 AI。用户可以返回暗房继续调整；在工坊中选择最终格式、尺寸、质量与文件名后，进入第三步。
3. **下载作品**显示实际导出的成品、尺寸、格式和文件名，再由用户触发浏览器下载。预览与下载引用同一份成品，支持 JPG、PNG、WebP。用户可返回水印工坊修改后重新生成。

## 本机数据边界

作者选择的共享示例随静态网站公开发布；发布器中的私人原片与凭据继续留在本机。访客临时会话使用独立的内存目录，不创建磁盘图库，不读取或更新先前图库的目录授权。选择照片只读取用户明确选择的文件，原文件保持只读。编辑参数、用户模板、Logo、草稿和导出结果只在当前页面会话中保留；关闭、退出或刷新后清空。需要长期保存的作品应先下载；图库入口用于另外建立持久图库。

导出采用现有渲染服务的 sRGB 与元数据策略：移除原片 EXIF、GPS、XMP，保留用户选择显示在相框中的可见文字。整个流程共用主题、液态玻璃、键盘操作与减少动态效果设置。
