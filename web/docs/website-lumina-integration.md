# 官网与新版光影集整合

整合目标是独立的 `photo_collection_web`。来源是“改版”中的 `photo_collection` 浏览器实现，源项目保持只读。此次整合不修改桌面安装、原有 99 项功能验收状态或下载页的正式安装包。

## 保留的官网逻辑

- `/`、`/en/` 继续展示作者选定的公开作品；轮播与精选分别读取 `coverIds`、`featuredIds`。
- 中英个人介绍、项目介绍、分享元数据和真实静态路由保持原样。
- `/windows.html` 沿用已有版本、包名、大小、校验值、HTTPS 下载和 GitHub 备用地址。
- 本机作者工具仍负责明确选片、构建和发布。公开包不包含作者组件或发布凭证。
- 日常预览仍使用 4175 / 4176；自动化使用独立的 4185 / 4186。

## 接入的新版应用

`/?local=1#/` 使用新版顶部附属导航、照片悬停信息、查看器、图库与影集、查询范围、创作工具、暗房、图层、LUT、相框、拼图和任务管理等浏览器实现。能力状态继续区分浏览器可用项与桌面专属项，不恢复远程后端或移动端产品。

原有“跳过，先浏览”继续提供空白的内存浏览状态，不创建图库或申请照片目录权限。浏览偏好也只写入这一临时状态，不消耗正式图库的旧设置迁移标记。导入时弹出图库选择，选好后直接继续导入；取消后回到原位置。暗房打开照片前同样要求选库，避免选库过程中丢失未保存编辑。

新版 v24 图库校验、迁移前备份、会话隔离、旧作品保留与原片只读规则沿用来源实现。公开作品导出可以在本机作者专用构建中使用新版来源检查，网站公开构建仍将作者入口排除。

## 材质与构建兼容

公开网站和应用分别启用各自的玻璃运行时，避免同一页面重复监听或覆盖主题。所有指针柔光均缩为各自原半径的 1/3：官网为 140 × 86.6667，应用大面板为 80 × 53.3333 CSS 像素；卡片与控件同样按比例缩小。静态环境背景不缩小，减少动态效果和高对比回退继续生效。

新版私有媒体通过 Service Worker 的 `/_pc-file/` 请求，由发起窗口按图库会话读取；这些文件不会发送给服务器或写入公开缓存。构建保留 `.mjs` / WASM MIME 和仅作用于视觉 Worker 的 WASM CSP。

ONNX Runtime 使用包内提供的外置 WASM 条件，与视觉 Worker 已指定的本机模块和 WASM URL 配套。这样不再输出无用且超过原托管单文件上限的 asyncify 文件；不修改依赖源码，也不下载模型权重。离线清单在 Vite 最后整理 CSS 资源之后生成，避免缓存已移除的空 JS 文件。

公开包检查明确允许玻璃资源、本地文件 Worker 和指定地图，并拒绝模型、数据库、日志、密钥、作者代码、未选照片及超过 25 MiB 的单文件。运行时依赖和模型权重不同：包内可以包含 WASM 执行引擎，用户的模型文件仍由本机显式导入。

可选中转的本地源码同步了新版请求编号与 AI 创作协议，协议校验和服务端实现留在独立 `cloud_relay` 包中，不引入桌面后端依赖。已有 `/cloud-art` 保持兼容；新创作协议使用 `/cloud-studio`，容器与 Caddy 源配置已配套。2026-10-28 已同步更新现有中转与 Caddy，两个协议的生产握手和来源校验通过。所有协议测试使用模拟响应，不产生付费请求。
