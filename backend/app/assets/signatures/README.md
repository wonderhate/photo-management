# Signature assets

`natural.png` is the user's original transparent lowercase `wonder` artwork, copied without modification from `wonder-signature.png` in the workspace. Reference: https://chatgpt.com/s/cx_6acc354321088191938e025c84b9e91a .

Three unmodified fonts are bundled from Google Fonts, each with its original SIL Open Font License 1.1 and copyright notice:

- Fine handwriting: Sacramento, https://github.com/google/fonts/tree/main/ofl/sacramento
- Brush script: Kaushan Script, https://github.com/google/fonts/tree/main/ofl/kaushanscript
- Classic calligraphy: Alex Brush, https://github.com/google/fonts/tree/main/ofl/alexbrush

Runtime rendering uses these local assets. No font installation or external connection is required. The original artwork remains a fixed `wonder` signature; the font styles support editable Latin text and fall back to the existing regular typeface for other scripts.
