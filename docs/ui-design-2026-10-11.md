# 光影集界面更新 · 2026-10-11

独立分支：`codex/netease-ui-redesign`。使用独立工作目录开发与验收，共享目录中的网页版与 Windows 同步开发继续保持原有结构。本分支包含前一轮尚未提交的英文界面补全。

参考网易云音乐桌面端的侧栏、留白和内容分区方式，采用浅灰导航、白色工作区、淡玫瑰色选中态，以及横幅和影集卡片组成的首页。参考入口：[网易云音乐官方客户端](https://music.163.com/download)、[桌面界面参考](https://www.mydown.com/soft/216/719709716.shtml)。图标沿用本项目网页版图案。

侧栏宽 228 像素，桌面内容区留白 40 像素；窄屏通过菜单访问全部功能。图库保留完整照片构图，支持拼排行和规则网格。报告、设置、水印编辑器、详情和弹窗使用统一的主题变量。侧栏文案为“收集光，收藏爱”。首次打开使用浅色模式，已保存的主题选择继续生效。

英文界面覆盖页面、提示、弹窗、日期和数量。切换语言保留未保存输入，照片文件名、标签、影集和人物名称保留用户原文。

Windows 可执行文件、窗口和安装器图标均从 `frontend/public/icon-512.png` 生成，包含 16 / 24 / 32 / 48 / 64 / 128 / 256 像素图标。

验证使用独立合成照片库：前端构建、14 项 Playwright 浏览器测试、5 项前端逻辑测试及 1 项 Windows 图标一致性测试。浏览器检查覆盖中英文、深浅主题、1440 / 390 像素布局、菜单键盘操作、照片布局切换、详情编辑、人物影集、路径设置以及水印保存和导出。水印流程结束后原始合成照片 SHA-256 保持不变。

模拟照片测试阻止 Service Worker，以保证合成图片请求由测试处理。原分支截图保存在忽略的 `verification/storage-paths` 目录，不进入发布包。

Windows 2.2.1 将本分支合入 `codex/android-remote-desktop`，保留 Android 2.0.0 的配对、远程编辑、电脑草稿、导出下载和索引缓存。合并后生产构建、45 项后端测试、14 项 Playwright 测试、6 项前端逻辑测试及 1 项图标一致性测试通过。新版截图保存在 `verification/windows-merge`。GitHub v2.2.1 的源码和安装文件同步本次界面更新，下载入口见 README。
