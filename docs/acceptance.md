# MVP 验收记录

> 历史 MVP 验收记录，不能作为当前 2.1.0 的完整网页验收结论。2026-10-10 本轮结果与仍待完成的浏览器交互检查见 [稳定性验收记录](verification.md)。

验证环境：Windows、Python 3.12.10、Node.js 24.19.0、Chrome headless、本地 CPU Chinese-CLIP。

| 流程 | 验证结果 |
|---|---|
| 100 张合成 JPG 导入 | 成功；不同镜头、日期、焦段与颜色，分页 20 条验证 |
| EXIF 标准化 | Rational 28/10、1/500、850/10，以及无效分母、NaN、缺失值处理通过 |
| 重复、损坏、无 EXIF | SHA-256 去重；损坏文件单独报错；无 EXIF 图片照常浏览 |
| HEIC、方向 | 实际编码 HEIC 后导入、生成预览成功；EXIF Orientation=6 正确旋转 |
| RAW+JPG 组 | 4 文件显示 2 次拍摄；报告同时显示 2 次拍摄 / 4 文件；不按相同时间误合不同名连拍 |
| 删除／移动 | 移出记录不删原文件；原图改路径后重导入可按 hash 重联 |
| 统计与报告 | 焦段分组、具体值、月报、年报、镜头分析及图库筛选通过 |
| 中文 AI | 实际本地模型索引 12 张照片；“城市夜景”优先道路夜景，“演唱会”优先舞台照片 |
| AI 缓存 | 搜索前后 .npy 文件修改时间一致，没有重复生成向量 |
| 智能影集 | 浏览器实际匹配 5 张候选、手动取消 1 张后保存 4 张，模型／关键词等配置持久化 |
| 两种水印 | 实际预览、单张导出、JPG／PNG 批量导出，暖冷色背景随照片改变 |
| 字段开关 | 取消镜头与 ISO 后从渲染数据中移除，缺失 EXIF 不显示占位字段 |
| 文件保护 | 重名自动编号；12 张现有照片逐一重新计算 hash，全部与导入时一致 |
| UI | 1440px 桌面、390px 手机宽度，无水平溢出；无 JavaScript 异常、无 API 5xx |
| Windows 启停 | 隐藏后台窗口启动、模型离线自动加载；正确停止 venv 启动器和 uvicorn 子进程，释放 8000 端口 |

最终后端回归：**17 passed**。浏览器脚本覆盖 **13 项流程**。浏览器截图和原始 JSON 结果位于本机 `verification/`。

## 合成数据库性能

50,000 文件、25,000 拍摄组；查询只访问 SQLite 标准化数据，不读原图。

| 操作 | 本机耗时 |
|---|---:|
| 年报 | 0.772 秒 |
| 月报 | 0.123 秒 |
| EXIF 统计 | 0.345 秒 |
| 镜头筛选分页 | 0.004 秒 |

以上不代表 50,000 张真实照片的导入、RAW 解码或 AI 索引速度。

## 尚未实际验证的环境

RAW 自动测试使用不可解码的占位文件来覆盖失败回退、配对和统计口径；未取得各品牌／机型真实 RAW 样片，不能据此保证所有 RAW 解码成功。CUDA 分支已实现，但本机验证使用 CPU。首次联网下载已成功，完全离线运行也通过本地模型加载验证。

当前队列为进程内队列，不提供进程中断后的自动任务续跑；重新导入会跳过已经持久化的照片。报告 PNG／PDF、复杂表达式、异名拍摄自动配对和专业 RAW 显影保留为后续扩展。
