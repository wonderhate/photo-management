# 图库与作品视图设置

此说明对应 AfterFrame 融合开发分支，不代表当前安装包已经更新。

| 范围 | 当前保存的内容 | 存储位置 |
| --- | --- | --- |
| 全局 | 明暗主题、语言、快捷键、首次使用状态 | 沿用当前浏览器配置与站点地址下的既有键 |
| 图库 | 四种照片布局、缩略图大小、间距、圆角、紧凑模式、普通排序字段与方向 | 桌面 SQLite `library_profile.preferences`；独立浏览器 `library.json` 的 `view_preferences` |
| 图库工具 | 查看器标准 / 4096 / 6144 清晰度及工具栏固定、对比同步开关、暗房导出格式 / 长边 / JPG 质量；拼图默认画布、格式 / 质量 / 缺口提示，以及批量分组 / 排序 / 余图 / 输出 | 桌面 `library_profile.preferences.tools`；独立浏览器 `library.json` 的 `tool_preferences` |
| 影集列表 | 名称 / 新建时间 / 照片数 / 自定义排序、方向、卡片顺序和卡片 / 表格模式 | 桌面 `library_profile.preferences.albums`；独立浏览器 `album_preferences` |
| 作品 | 暗房工程的预览缩放 | 桌面 `document_view_preferences`；独立浏览器对应编辑记录的 `view_preferences` |

普通排序与影集手动顺序分开。进入影集仍默认手动顺序；离开后回到该图库保存的普通排序。启动仍显示摄影空间，打开保存的深链接仍进入对应页面。查看原图、展映播放、临时选择和未保存编辑不作为全局偏好保存。

普通字段现包括拍摄时间、导入时间、文件名称与评分。缺失值置后、同值以稳定 ID 排列；评分修改 / 清除后即时重排，选中照片按 ID 保留。具体规则和分页边界见 [照片排序](photo-order.md)。

影集列表设置与照片排序、影集内部照片顺序分别保存。新建影集回到自定义顺序首位，名称搜索只筛选显示，不丢弃隐藏影集的编排。重命名不改变成员或封面。具体操作见[影集列表](album-list.md)。

首次打开一个图库时，迁入旧 `gallery-layout`、`grid-size`、`grid-prefs` 中有效且有界的字段。已保存的图库字段优先。成功迁移后，其他图库从自己的偏好或默认值开始；旧键不再跟随每次调整改写。无法读取浏览器存储时基础浏览仍可用，持久化失败会显示提示。全局设置的共享范围仍受浏览器配置、站点地址与端口影响，不是跨浏览器同步。

图库设置在停止调整 350ms 后合并写入，仅更新改变的字段。已取得图库身份后，每次调整也立即写入该标签页内按图库隔离的临时记录，刷新后恢复尚未写完的修改；写入成功后清除临时记录。初始异步读取不会覆盖用户刚做的调整。「关闭图库」先等待待写设置和已发起的作品视图保存，再关闭。突然终止浏览器、系统断电或尚未读到图库身份时刷新，仍可能中断最后一次写入；标签页临时记录不能代替持久备份。

独立浏览器的关闭操作在当前页面返回图库选择页；先持久保存后台任务的取消状态，再清除本次会话密钥和媒体引用。重新打开另一图库生成新的会话代次；旧任务和排队元数据写入不能更新新图库。已完成文件保留，刷新后未完成工作只标为中断，不自动执行。桌面采用独立的受管理进程重开流程，不把浏览器同页关闭／打开能力当成桌面数据库热切换。

每个存储适配器绑定打开时的图库 ID。桌面写入由本机服务再次检查 ID 和进程会话，使用 SQLite 写事务合并；独立浏览器排队执行时再次检查 ID、会话代次及目录对象，即使关闭后重新打开同一 UUID，旧适配器也不能写入。沿用清单 revision 检查与上一份元数据备份。跨窗口修改同一独立浏览器图库时仍要求重新打开，不能自动覆盖冲突。

工具设置同样使用 350ms 合并和标签页临时记录。立即离开再进入工具时，先等待上一个页面已登记的设置写入，再读取新快照；晚返回的读取不会覆盖已操作字段。白底校样、查看缩放 / 拖动、当前照片、播放、全屏与临时选择不保存。暗房尚未设置工具偏好时沿用图库的导出默认值；改变工具选项只保存其覆盖字段，不更新编辑参数、版本或草稿。无效长边可以暂留输入框供修正，但不会持久化或导出。

桌面 schema 3 增加稳定 UUID 身份。新库首次创建时生成；正常重启、路径迁移、数据库备份与恢复保持身份。复制备份视为同一图库的恢复副本；「另建独立图库」生成新身份。合并保留目标库身份和目标浏览偏好，并为源工程重映射作品视图关系。当前融合分支提供 [最近图库选择与受管理重开](catalogs.md)，通过进程边界隔离旧任务、模型和媒体；普通本机服务仍由原启动方式重启，不在已加载进程中替换数据库全局变量。

缩放保存不会更新源快照、recipe、revision、作品渲染或原片。另存新工程会记住当前缩放；重新打开已保存工程恢复该工程的缩放；打开另一张新照片从适应窗口开始。拼图偏好也已接入该作用域：新建等待设置加载，已有工程保持自己的画布和分组；输出格式、质量与提示不写入布局清单。详见[照片拼图](photo-collage.md)。后续工具偏好继续沿用相同约束。
