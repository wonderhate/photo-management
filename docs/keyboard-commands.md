# 快捷键与操作菜单（融合开发分支）

图库、原照片查看器和编辑工坊共用一个快捷键登记表。设置、帮助、操作菜单和工具按钮读取相同绑定；修改后立即生效，刷新或切换图库保留。旧的自定义绑定优先，和新增默认键冲突时，新命令显示“未绑定”，不会覆盖旧配置。

## 编辑器默认键

| 按键 | 操作 | 当前支持 |
| --- | --- | --- |
| `Ctrl + O` | 打开照片 | 暗房打开本机文件；水印 / 水彩打开已有选片入口 |
| `Ctrl + Shift + O` | 打开参考图 | 暗房 |
| `Ctrl + Z` / `Ctrl + Y` | 撤销 / 重做 | 暗房、水印 |
| `Ctrl + S` | 保存 | 暗房编辑参数、水印草稿、水彩本地排版 |
| `Ctrl + E` | 导出副本 | 暗房另存下载、水印当前照片、水彩 PNG |
| `B` | 原图对比 | 暗房、水彩 |
| `0` | 适应窗口 | 暗房 |
| `+` / `-` | 放大 / 缩小预览 | 暗房沿用适应 / 150% / 200% 档位 |
| `Ctrl + 0` | 重置参数 | 暗房，可撤销 |

取消处理、标记待导出、批量水印导出、送入水印 / 水彩也在同一表中，默认不分配按键；可在设置中重绑。只在当前工坊提供相应操作，沿用既有能力和可用条件。打开参考图需要已有照片，重做需要相应历史，桌面尚未支持的编辑副本送水彩仍不可用。

查看器继续使用上一张 / 下一张、收藏、标签和缩放 / 白底等既有绑定，见[照片查看说明](photo-viewer.md)。图库 `Ctrl + E` 仍进入所选照片的水印导出流程；编辑器里的相同按键只导出当前作品。

## 输入和执行规则

普通字母、组合键与 Shift 组合分别识别；`?` 和 `+` 按键盘实际产生的字符处理。录制时冲突会提示，Esc 取消，Tab 继续正常移动焦点；Alt 组合不登记为无法执行的普通字母。

输入框、文本区、选择框、可编辑内容和快捷键录制优先处理自己的按键。因此在文字输入中使用撤销、删除等，不会触发照片或作品操作。需要执行工坊命令时，先将焦点移到页面空白处或工具按钮。输入法组合输入期间不派发命令。

弹窗和打开的菜单阻止后台快捷键。菜单支持方向键、Home / End、Enter、Tab 和 Esc，关闭后恢复触发按钮的焦点。查看器中第一次 Esc 关闭菜单，再次 Esc 关闭照片；在全屏查看器内，菜单与帮助弹窗仍显示在全屏容器中。

菜单、按键和对应工具按钮调用相同操作及可用条件。忙碌时不可用的命令不会触发浏览器替代操作；保存 / 导出等不接受按住按键产生的重复请求，同一未完成操作也不会重入。撤销、重做和浏览缩放仍可连续按键。

## 原片与云端

保存和导出沿用已有实现：暗房保留只读来源，水印保存草稿，水彩仅保存本地排版。水彩保存仍要求标题确认，未保存排版仍不能导出；快捷键不绕过条件。菜单没有生图、标题建议或自动重试命令。打开水彩选片或送入工坊不等于提交云请求。

2026-10-22 最终完整检查：桌面服务浏览器 100 项、本地 Web 63 项、前端逻辑 56 项、后端 123 项通过，两种构建和图标检查通过。新增检查包含实际保存 / 导出、原片哈希、重复请求、输入 / 录制 / 模态、Shift 重绑、全屏菜单和帮助。真实 Windows WebView、硬件和发行包仍需 M7 验收；完整融合尚未全部完成。详细证据见[融合实施记录](afterframe-upgrade.md)。
