# 实时人物照片与人物影集快照

Windows 桌面及连接本机服务的网页支持此功能。独立浏览器图库仍没有人物分组或人物模型，本次不增加云端替代分析。

## 两个浏览入口

人物卡片的“实时人物照片”会进入原有照片库界面，范围固定为这个人物的当前关联。可以继续搜索、筛选、选择、对比、查看原有大图、使用水印等工具。“查看照片”保留原来的分组检查和人物照片区域；从这里双击照片，大图也只在该人物的照片内翻页，不再使用全库列表。

实时范围包括待确认关联，页面会显示待确认数量；自动分组仍是建议，需要人工检查。新识别、重新关联、移出和改名会反映到当前人物范围。按拍摄或按文件沿用现有计数口径：按拍摄显示优选文件，按文件可以浏览同一拍摄中的配对文件。

“打开人物影集”和“新建人物影集”继续保留。人物影集是普通影集的已保存成员快照，仍可手动编辑；之后新增识别、移出或重新分组不会自动改写其中的照片、顺序、封面或人物关联。范围栏明确标示“人物影集快照”，有关联人物时可以主动切到“查看实时人物照片”。

## 更新与浏览体验

实时页面可见时，约每 5 秒检查一次少量人物关系信息；有变化才更新照片列表，也可点“刷新人物匹配”。搜索和临时筛选始终在这个人物范围内求交集，更新不会清除输入或扩大到全库。刷新页面及前进、后退继续保存原有检索范围。

查看大图时保留当前翻页序列，暂停此项自动同步；关闭大图后立即核对最新关系。页面离开或隐藏时停止相关请求，回到页面后再检查。迟到的旧人物响应不会替换新人物的名称、列表或错误状态。

人物被合并时，原范围会显示合并目标的入口，由用户主动打开目标人物；不会悄悄替换原条件。已忽略的明确人物范围仍可读取已有记录，并显示忽略提示。人物已删除、来源不匹配或图库不匹配时保持错误与原范围，不自动退回全库；主动点“返回全部照片”才解除。

## 实现与数据保护

复用现有 `QueryScope`、人物条件查询和原照片浏览器。新增只读 `/api/faces/persons/{id}/scope`，绑定图库身份与计数口径，在一致的 SQLite 读取事务中核对人物名称、合并 / 忽略状态、人脸关联 ID、确认状态、拍摄组及当前查询得到的照片 ID。完整关系摘要能够发现数量不变的成员调换，以及按拍摄时优选文件的变化。

关联元数据按批次读取并形成小摘要，不读取人脸向量、原图路径或图片，不加载模型、下载权重、重新识别或上传照片。未变化时不反复下载整份照片 ID 列表。检查不新增持久字段，SQLite **schema 14** / 浏览器 **manifest 10** 保持。

范围仍属于当前图库；不同图库、人物 ID、计数口径及页面生命周期分别核对。大图请求复用原取消与来源检查，人物区域打开时先固定当前照片，再接入该人物的翻页序列，防止迟到结果带入其他照片。

测试使用合成照片和受控本地识别响应，检查新增识别后实时列表增长且旧快照不变、成员调换、RAW/JPEG 计数、合并 / 忽略 / 删除、跨库拒绝、2000 条观察仍只返回少量元数据、原片 SHA 及中英文实际浏览流程。这不代表真实人脸识别准确率或完整大规模人物性能已经验收。
