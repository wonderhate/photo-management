# 手机选择电脑照片

分支：`codex/phone-computer-file-picker`，基于两端 UI 同步分支。Windows 2.2.4 提供更新后的共享前端与目录浏览接口，Android 2.0.1 无需更新 APK，重新连接更新后的电脑即可使用。

手机导入入口：选择照片或文件夹 → 在手机浏览电脑的用户文件夹、磁盘与子目录 → 确认选择 → 开始导入。支持跨目录多选照片、200 项分页、上一级导航、直接输入电脑绝对路径、文件夹导入与包含子目录选项。取消选择保留之前的待导入路径。

目录接口仅返回文件夹和支持的照片文件名称、路径，不读取或传送照片内容。沿用电脑远程访问的配对、会话和撤销权限，目录响应不缓存，拒绝相对路径、UNC / 设备路径与不存在的目录。目录无权限时显示错误，不误报配对失效。手机不会触发电脑原生文件窗口；电脑本地访问继续使用原生选择器。

导入沿用现有 `/api/photos/import` 任务：登记电脑原文件路径、读取 EXIF、去重；不把文件复制到手机，也不创建导入副本。图片内容仍由电脑预览接口处理。

验证使用隔离合成库，覆盖配对权限、照片后缀过滤、目录与分页、多选、确认和取消、中英文、手机宽度、实际导入以及原文件哈希。

本机结果：后端 47 项、前端逻辑 6 项、生产浏览器 22 项检查通过；最终手机选择器在 360 / 430 × 720 的中文和英文界面中通过完整流程检查。实际 Windows EXE 的 10 项界面检查通过，包括电脑文件选择、实际导入与原文件哈希。Android 2.0.1 正式 APK 在 API 35 专用模拟器中通过电脑目录浏览、照片选择、导入以及原有配对、创作和相册导出流程。预览保存在 `verification/phone-file-picker/`。

安装器为 `releases/PhotoCollection-Setup-2.2.4-x64.exe`，便携包为 `releases/PhotoCollection-Windows.zip`。原 Android 2.0.1 APK 不变。用户正式图库和安装位置未用于上述测试。
