## 设计落地

参考分析见 [网站布局与动画分析](chuweimin-ui-animation-analysis-2026-10-11.md)。

| 建议 | 实现 |
|---|---|
| 黑色展场、层次灰、少量金色 | 统一颜色、间距、边框和选中态；亮色主题使用暖白底 |
| 中文衬线表达、无衬线操作 | 首页、页面标题、影集标题使用衬线；控件、表格、参数使用无衬线 |
| 一张主推与次级作品 | 摄影空间首页读取已有照片与影集：封面、1+4 影集区、工作入口、近期照片 |
| 保持照片比例的拼排行 | 新增虚拟拼排，保留规则网格、尺寸、间距、圆角、紧凑模式 |
| 大图、缩略图和 EXIF | 沉浸详情、邻近照片胶片条、信息侧栏、键盘与触控切换、全屏 |
| 直接操作反馈 | 筛选、选中、收藏、标签与按钮反馈；表单和编辑预览保持稳定 |
| 全屏菜单与窄屏布局 | 手机全屏导航、单列首页、触控按钮、弹窗焦点约束及关闭后恢复 |
| 渐进加载与滚动出现 | 图库加载完成后显现；首页内容区进入视口后出现一次 |
| 封面慢速切换 | 可手动选封面，轮播由用户开启，可随时暂停 |
| 光圈开场与摄影叙事 | 摄影氛围开关：首次开场可跳过，快门闪光、显影、颗粒和取景框 |
| 极光、雪、手电筒与列车 | 可选展映模式；手电筒可开关，列车速度可调，播放可暂停并可返回普通浏览 |
| 减少动态效果 | 遵循 prefers-reduced-motion；窄屏停用持续装饰动画，内容与所有操作保留 |

默认入口仍是照片库；点击品牌或“摄影空间”可进入首页，直接地址为 `/?page=home`。展映和摄影氛围由用户开启，照片管理流程继续使用原有接口。
