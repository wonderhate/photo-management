# 用户自定义照片库与存储目录 · 2026-10-11

实现分支：`codex/storage-path-settings`。目录设置使用普通输入框和既有文件夹选择器，不增加依赖。

## 使用

在「设置 → 照片库与存储」编辑数据库与缓存、模型缓存、导出目录及自动扫描照片目录，点击「保存目录设置」。待生效修改会持久保存，可以在重启前取消。网页刷新仍使用原库；关闭其他光影集实例后重新启动程序才会应用修改。

新照片库必须是空目录。程序在打开数据库前复制当前库及其管理的文件，完成数据库完整性、外键和路径转换后切换。旧库、外部原图和历史导出保留，不会覆盖目标目录的既有文件。浏览器上传文件会复制到新库，旧副本仍保留。模型目录仅切换使用位置，新目录为空时需要重新准备模型。

Windows 打包版将个人配置保存在 `%LOCALAPPDATA%\PhotoCollection\library-config.json`，旧 EXE 同目录配置作为兼容回退；源码版仍使用项目配置。显式指定数据目录的实例使用自己的配置文件，启动环境指定的路径不能从界面覆盖。`PHOTO_LIBRARY_CONFIG` 可指定独立配置文件，供隔离启动和部署使用。
