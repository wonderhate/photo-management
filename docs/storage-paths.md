# 照片库与存储目录

当前版本 2.6.1。目录设置通过既有文件夹选择器或绝对路径输入完成。融合开发分支另提供 [多图库选择与最近图库](catalogs.md)，用于直接打开已有库或新建独立空库；下述入口继续负责复制迁库。

## 使用

在「设置 → 照片库与存储」编辑数据库与缓存、模型缓存、导出目录及自动扫描照片目录，点击「保存目录设置」。待生效修改会持久保存，可以在重启前取消。网页刷新仍使用原库；关闭其他光影集实例后重新启动程序才会应用修改。

新照片库必须是空目录。程序在打开数据库前复制当前库及其管理的文件，完成数据库完整性、外键和路径转换后切换。旧库、外部原图和历史导出保留，不会覆盖目标目录的既有文件。浏览器上传文件会复制到新库，旧副本仍保留。模型目录仅切换使用位置，新目录为空时需要重新准备模型。

Windows 打包版将个人配置保存在 `%LOCALAPPDATA%\PhotoCollection\library-config.json`，旧 EXE 同目录配置作为兼容回退；源码版仍使用项目配置。显式指定数据目录的实例使用自己的配置文件，启动环境指定的路径不能从界面覆盖。`PHOTO_LIBRARY_CONFIG` 可指定独立配置文件，供隔离启动和部署使用。

## 备份与恢复

数据库备份接口仅保存元数据。完整备份应在关闭所有应用实例后保存整个库目录，包含 `imports/`、`watermark_previews/`、`artworks/`、`export-records/` 及其它派生数据；融合开发分支还包括 `documents/edits/` 工程源快照和 `assets/variants/` 编辑副本，见 [共享暗房说明](shared-darkroom.md)。外部原始照片和历史自定义导出目录另行保存。只复制 `library.db` 不会包含水彩成品、暗房源快照或浏览器导入副本。

迁移包含水彩的场景、全部已保存海报版本和 `qwen-art-key.dpapi`。海报旧版本可能仍被水印草稿引用，不能按文件时间直接删除。DPAPI 密钥与 Windows 用户绑定，跨电脑或用户恢复时可能需重新配置。

迁移失败时保留旧库并显示错误；先确认权限、空目录和可用空间，再重启重试。旧库应在新库验证完成并另有备份后由用户自行处理，程序不自动删除。

测试及优化入口见 [开发交接](development-handoff-2026-10-13.md)，不要把历史检查数量当作最新基线。


### AfterFrame 升级的恢复边界

SQLite 升级先建立并检查完整备份，再提交 schema 变更；不支持的更高版本会拒绝打开。备份暂存目录不代表有效的备份文件。跨盘迁库在目标卷暂存完整副本，校验托管文件后一次发布；外部原片保持原路径，旧库保留。复制失败或磁盘满时继续使用旧配置；清理空间后可取消待迁移设置并重新选择一个空目标目录。

进程在发布副本后、保存配置前退出时，旧配置仍是有效回退。不要覆盖已经存在的目标库；重开旧库后取消待迁移设置，通过图库选择功能检查并选择完整目标库，或使用另一个空目录重新复制。`.photo-library-copy-*` 是尚未发布的暂存目录，不要将其当作已经完成的图库。

受 Windows 用户绑定的凭证按字节保留。更换用户或电脑后无法解密时，原库和其他照片功能仍保留；在水彩设置或相应 AI 账户重新保存该服务的密钥。不会使用 OpenAI 密钥或另一个 AI 账户兜底。SQLite 数据库备份本身不包含派生图片、外部原片或模型；完整迁库与浏览器完整备份才包含相应托管文件。
