# 照片拼图（融合开发分支）

Windows 本机界面和独立浏览器共用拼图工具。在「工具」中打开「照片拼图」并添加本地照片，或在图库选中照片后点击「照片拼图」。原片只读；当前批次不调用 AI，也不上传照片。

## 布局与取景

按照片数量提供 80 种布局，支持 1–12 张照片。对应模板数为 1、6、10、10、10、9、9、6、5、5、5、4。界面只显示当前数量可用的布局，超过 12 张明确拒绝，不丢弃多余照片。

可设置画布宽高、格子间距、画布留边、圆角及背景色。宽高支持 100–12000 像素，输出不超过一亿像素；会造成格子消失的间距组合不能应用。尺寸输入在离开输入框或按 Enter 时确认，Escape 恢复当前值。

点选格子后拖动调整取景，也可用方向键微调，按住 Shift 加快。将照片拖到另一格并松开可交换；会撤回拖动过程中的临时取景，保持照片原有缩放与位置。指针取消或意外失去捕获时撤回本次临时拖动。支持滚轮缩放、Ctrl 触控板捏合和屏幕双指缩放，连续滚轮操作合并为一个撤销步骤。拖动接近中心 8 个显示像素时吸附，按住 Shift 可绕过吸附；辅助线只在操作中出现。「居中照片」只重置位置，保留缩放。格内缩放范围为 0.25–5 倍；「重置取景」恢复居中填满。「交换照片」可用键盘操作，交换后照片身份、取景位置与缩放一起移动。替换照片保留当前布局，未替换照片的取景继续保留。移除照片后使用新数量的首个布局，不能移除最后一张。

画布提供 1:1、4:3、3:2、16:9、9:16 比例按钮，保留当前长边并按像素取整；1600、2400、4096、6144 长边按钮保持当前宽高比。纯黑、纯白和象牙白快捷色与自选纯色共存。可以关闭缺口斜线，未填满数量的文字提示仍保留。显示提示、PNG/JPEG/WebP 格式与质量按图库记忆，不写入来源 / 布局清单。

当前窗口保留最近 50 步布局、位置与样式撤销 / 重做。添加、移除、替换原图或恢复清单会重新建立来源会话并清空撤销历史；这些来源变更还没有跨会话撤销。未填满的格子显示预览斜线和文字提示，斜线不进入输出。面板沿用当前主题、提供中英文和窄屏排版，没有新增强制动效。

## 保存与恢复

「保存布局清单」下载版本 2 的 `Collage.pc-collage.json`。清单包括模板、画布、每格取景，以及完整来源登记：名称、SHA-256、源尺寸、解码位深、解码版本、来源标识；从图库打开时还包含照片 ID。清单不包含原片字节、文件绝对路径或凭证。

重新打开清单后，主动选择清单中的全部原图。按文件内容哈希匹配，选择顺序和外部重命名不会改变布局来源。缺图、内容变化、未知版本、重复来源标识或无效参数会报错，保持当前已打开的拼图。清单 JSON 字段排列顺序不影响恢复。

清单由用户下载保管；也可使用下述「保存到图库」保留完整工程。关闭有未保存修改的窗口会提醒。图像导出不替代工程或布局清单保存。

## 预览、导出与资源

使用现有 LibRaw-WASM / 普通图像解码链路，RAW 读取完整 16 位源数据，再按暗房中性显影输出 8 位 PNG、JPEG 或 WebP。PNG 无损，JPEG / WebP 质量可选 1–100；预览始终使用 PNG，格式选择不改变预览和取景参数。普通图像沿用现有方向规则。当前不提供 16 位 PNG 或色彩管理输出，也不把相机 JPEG 当作 RAW 全量解码结果。

工作线程只缓存每张源图最长边 1000 像素的显示位图；预览画布最长边也是 1000。导出逐张重新读取完整源文件，核对 SHA-256 和尺寸并解码，按完整输出几何合成，不把预览图放大。模板共享边界按最终像素坐标取整，预览按相同几何缩放。每张导出位图绘制完成即释放，替换来源成功后释放旧缓存；关闭窗口终止会话和未完成的读取，旧来源会话的迟到预览不发布。连续调整采用每次只执行一个预览、最多保留一个最新待处理状态；完成的帧可在后续帧处理期间显示，不必等待拖动停止，也不堆积过时任务。

来源合计不超过 512 MiB，单个文件不超过 256 MiB，单张解码不超过一亿像素。上述为文件和像素边界，不是总内存上限；解码、画布和编码仍会占用额外内存。工作线程请求超时为 180 秒。失败不自动重试或覆盖原片。

## 批量拼图

在单页工具中点击「批量拼图」，会携带当前照片的视觉顺序和取景；从图库选中超过 12 张照片打开拼图时直接进入批量模式。单批最多 240 张、文件总量不超过 512 MiB。读取逐张进行，失败或停止保留原有批次，不截取前 12 张冒充完整导入。

每组可选 2、3、4、6、9 张，按选择 / 手动顺序、文件名或拍摄时间排列。拍摄时间沿用本地 EXIF / RAW 元数据读取；缺失时间的照片排在最后，缺失者按文件名排。相同时间保持原顺序。余图可单独成页、合并上一页或跳过并列出。合并超过 12 张时改为独立页；跳过的照片仍保留身份与取景，修改余图策略可恢复。重新分组会按页位置沿用画布样式，照片取景随来源保留；模板仅在格子数量相同时沿用。

各页使用原单页编辑器，可调整模板、取景、画布及颜色，点击「应用并返回批量」确认；编辑本页时不替换、增删来源。可将本页尺寸 / 间距 / 留边 / 圆角 / 背景应用到全部，同格数页面同时使用本页模板。批量窗口支持最近 10 次布局操作撤销；增加或恢复来源清空此历史。

可以跨页拖换照片，或选中照片格后用目标列表交换。交换保留来源、缩放和位置，并将当前视觉顺序固定为手动顺序。批量清单 `Collage.pc-collage-batch.json` 为独立版本 2，记录所有来源、分组规则、各页布局和跳过照片取景。重新选择全部原片后按 SHA-256 匹配恢复；清单不含原片、路径或凭证。清单下载与图库工程保存为独立入口，均由用户主动操作。

### 逐页导出与恢复

选择 PNG、JPEG 或 WebP / 质量，主动开始导出。各页复用完整来源渲染器，逐页创建并释放 Worker，单页仍逐张解码完整源数据并复核哈希。失败页不影响后续页；停止会中止当前处理并保留成功页，未处理页保持待导出。点击「导出未完成页」才重试失败 / 取消 / 待导出页，已完成页不重复处理。

「下载已完成页 ZIP」包含已完成图片、逐页状态报告及完整批量清单，不含原片。ZIP 使用标准 STORE 格式，已压缩图片不再重复压缩；生成包前读取各图片计算 CRC。图片总量上限 250 MiB，整个包上限 256 MiB。超限页标为失败，可下载已有成功结果后降低输出尺寸；当前不会自动拆分为多个包。输出格式和质量在已有成功结果时锁定，清除结果后可更改；它们写入导出报告，不作为恢复清单的布局设置。

布局修改会清空当前导出结果；有未下载的结果时先提醒。关闭时提醒未保存布局、处理任务与未下载结果。下载完成表示已发起浏览器下载，最终文件保管由用户负责。

预览按可见页面排队，共享一个 Worker；最多缓存 24 张、最长边 360 像素的页面缩略图。离屏未开始的工作取消排队，导出期间保留小预览并停止预览解码，返回可见区域按需补齐。编码结果总量边界不等于浏览器总内存限制，RAW 解码和画布仍需要额外内存。原有主题变量、双语和减少动态效果设置继续适用。

### 与参考实现的取舍

分组数、排序和三种余图处理对照固定版本的 `collageBatch.js`；超过模板上限时单独成页，保留其防止静默丢图的规则。本项目额外明确展示被跳过照片，保存其取景，校验恢复来源，并记录每页成功 / 失败 / 取消状态。批量出口使用通用 ZIP，兼容 Windows 与本机网页版；拼图作品库提供主动保存、来源查看及布局副本恢复，两端共用；不把派生拼图计入原照片和拍摄数量。图库工程列表、源图快照及备份也已接入。

## 接缝融边与画布重置

「接缝融边」滑块快速调整 0 至画布短边的 10%；「融边精确宽度」可输入 0–10000 输出像素，更宽值由精确输入框显示。零表示关闭。两端预览、PNG/JPEG/WebP 正式导出及批量导出共用这一参数。相邻照片向内部接缝两侧延伸，在带状重叠区通过相反方向的线性透明度渐变相加；横纵接缝相交时渐变相乘。开启后填合内部间距，保留圆角数值但不绘制圆角，外部留边保持且外侧边缘不羽化。过大的宽度会跨越多个格子，按参考实现缩短相遇的渐变坡道，视觉效果不同于局部接缝，应结合预览调整。

内部接缝位置直接从模板比例计算，避免奇数像素间距各自取整造成两侧不同心。预览按输出尺寸缩放同一几何；取景拖动、居中吸附及未填满检查使用扩展后的照片范围。缺口斜线仍只在预览显示，正式输出不含辅助线或单元格按钮。开启融边会改变照片的填满范围，之前相同的缩放参数不等于相同的裁取边界；关闭后按原边界绘制。

「重置画布设置」恢复 2400×2400、默认间距 / 留边 / 背景、零圆角与零融边，保留照片身份、布局模板及各格取景，支持撤销。单页样式应用到全部、重新分组和单页转批量均携带融边宽度。增加、替换照片时沿用当前画布设置。

单页与批量清单升级为版本 2；读取版本 1 时复制升级，明确补零融边，不修改旧文件。版本 1 不允许携带新融边字段，未知版本或缺少 / 超出范围的参数拒绝读取，防止旧工具静默忽略效果。这次融边不改变暗房配方版本；之后的工程持久化另行升级数据库和图库格式，见下文。

渲染在一个透明输出画布上叠加带权照片，最后合成背景；每张完整源图处理后立即释放。临时层采用分条绘制，单条不超过 400 万像素，处理完即缩小释放。这个边界不包含完整输出画布、源图解码和浏览器内部编码缓冲，不应解读为整个导出的内存上限。

算法对照固定 AfterFrame 版本的 `collageRender.js`，保留 MIT 来源记录；在本项目适配 OffscreenCanvas、顺序源图解码、未取整接缝及临时画布分条。画布重置对照 `PanelControls.jsx`，恢复本项目已有默认配色和尺寸。


## 图库内工程与来源快照

单页和批量窗口均提供「工程名称」「保存到图库」和「图库内拼图工程」。保存后可继续覆盖当前工程，或「另存拼图工程」建立独立记录。列表每页 20 项，默认按最近修改排序，可搜索工程名称并切换名称 / 修改时间及升降序；打开工程自动读取并核验来源，无需重新选择原片。保存包含布局、分组、全部取景、被跳过的照片及解码参数；格式、编码质量、临时导出结果与撤销历史不包含在内。没有自动保存。

每份工程保存源文件的只读快照，按 SHA-256 去重；再次保存复用该工程已有的完整快照。图库照片 ID 仅在当前照片记录及内容匹配时建立关联。移除照片记录或移动外部原片后，工程仍从自身快照恢复；读取时再次核对哈希，损坏时明确报错，不悄悄替换来源。快照会占用本地存储，不等同于只保存参数的轻量清单。

保存和删除均检查版本号，其他窗口已修改时要求重新打开，避免覆盖。相同请求重试返回原记录，不重复创建；失败时只回收确定未发布的本次新快照。切换图库后迟到的保存不能进入新库。打开另一工程读取失败时保留当前编辑窗口及内容。

删除只移除工程记录，原片不受影响；已经保存的托管快照暂时保留，尚未接入资产回收界面。删除当前工程后继续编辑可重新保存为新工程。工程修订号用于冲突检测，目前不提供工程每次保存的历史回退；已保存作品单独保留导出时的布局和来源，可恢复为新副本。

工程持久化最初使用 Windows schema 22，使用 `collage_projects` 与图库 `documents/collages/` 保存参数及源快照；纯浏览器最初使用版本 18，使用 `collages` 与 `drafts/collages/`。两端沿用升级前备份，备份失败不提交升级。Windows 复制迁库会改写托管路径，合并库会处理工程 ID 冲突和照片 ID 关联；网页版完整图库备份包含快照并可重新打开。仅复制 SQLite 数据库不是完整工程备份，需同时保留托管文件。新模板校验副本随后端打包，仍沿用上述 MIT 来源授权。


## 默认偏好与操作入口

「设为新拼图默认画布」保存当前尺寸、间距、留边、圆角、背景与融边。仅新建拼图采用该设置，当前工程、打开的布局清单和已保存工程保留各自样式。「恢复默认画布偏好」也只影响后续新建，不重置正在编辑的画布；需要改当前画布时使用原有可撤销的「重置画布设置」。偏好不保存照片、取景或模板。新建批量页采用默认画布，从单页携带布局转入批量则保留携带的样式。

单页输出格式、编码质量与缺口提示按图库保存；批量的每组张数、排序、余图策略、输出格式与质量独立保存。未设置时仍为原有四张分组和 PNG。加载偏好完成后才创建新布局，避免迟到设置覆盖用户刚开始的编辑；打开已有批量工程仍以该工程的分组设置为准。

右键照片格，或聚焦格子后按菜单键 / Shift+F10，可替换、移除、居中或重置取景；最后一张不能移除，批量的单页编辑不增删或替换来源。菜单关闭后恢复焦点。点击画布空白处取消格子选择；画布聚焦时按 Escape 先取消当前选择，不直接关闭整个工具。

仅修改工程名称也会触发未保存提醒，关闭、打开其他工程或离开当前编辑时均受保护。保存后解除该名称的未保存状态；图像下载不等同于保存工程名称。

## 工程检索与来源信息

搜索在分页前按名称包含关系筛选，`%` 与 `_` 按普通字符匹配，英文字母不区分 ASCII 大小写；中文按原字符匹配。名称排序与修改时间排序都支持升降序，同值用工程 ID 稳定排序。查询上限 120 字符，每次搜索显示匹配总数；清除搜索恢复全列表。

每项工程可展开保存时的来源记录：文件名、源尺寸、解码位深 / 版本、SHA-256，以及图库来源或本地快照说明。批量工程还显示照片所在页和当前跳过状态。这里展示保存的历史记录，不表示图库原照片记录此刻一定存在；打开工程时才读取并复核快照。界面不展示源文件绝对路径。

WebP 与 PNG/JPEG 共用全分辨率来源和几何，单页直接下载，批量输出 `.webp` 并收录 ZIP。编码后检查实际 MIME；运行环境不支持请求格式时明确失败，不把回退 PNG 冒充 WebP。WebP 为质量可调的有损输出，不承诺与 PNG 像素一致。预览仍为 PNG，辅助线不进入导出；不嵌入原片 EXIF/GPS，当前没有额外 ICC 色彩管理输出。


## 拼图作品库与冻结来源

先「保存到图库」保存当前工程，再点击「保存拼图作品」。单页会按当前输出格式 / 质量重新渲染完整尺寸并登记作品。布局或名称已变动时，须先保存工程，防止作品指向旧参数。普通下载仍然可用，不会自动建立作品记录；所有保存都是用户主动触发。

批量模式先完成逐页导出，再点击「保存已完成页到作品库」。只登记已有成功结果，不重渲染失败或未完成页；某页登记失败不妨碍其他页保存，界面逐页说明失败。再次点击时，同一窗口中同一工程版本、页面、格式、质量和内容使用相同请求标识，已提交记录不重复创建。关闭重开后的主动保存可产生新的作品记录；这不是全库内容去重。

每条作品保存编码图片、SHA-256、格式 / 质量、尺寸、页码，以及导出时完整工程版本、布局、所有来源登记和只读快照引用。随后修改或删除工程，不会改变已保存作品。批量作品的来源快照包括整个批次和跳过照片，以便恢复整套布局；快照引用复用已有不可变文件，不重复拷贝源图。查看或恢复时继续核对文件哈希。

「拼图作品库」每页显示20项，按保存时间排列，提供「预览与来源」「下载作品」「恢复布局副本」和「删除作品记录」。只有主动预览时读取图片，不为整个列表同时解码全尺寸图片；关闭预览或窗口释放对象 URL。下载得到保存的原编码字节，使用含作品 ID 的独立名称，不覆盖源文件。恢复副本读导出时快照，保存为新的工程；不会覆盖仍存在的当前工程。读取失败 / 取消时保留原编辑窗口。

删除作品只移除该记录，保留原片、工程及已发布托管图片 / 源快照；清理空间的资产回收界面仍待全局存储阶段。删除后可再次保存当前输出。作品在专用拼图作品库内管理，不混入原片计数。当前没有从拼图作品直接跳入水印 / 水彩或暗房的入口；全局派生图关系与工具间联动属于 AF69，不能据本节声称全部实现。

本批数据库升级为 **schema 23**，新增 `collage_outputs` 和 `documents/collage-outputs/`；浏览器清单升级为 **19**，新增 `collage_outputs` 和 `drafts/collage-outputs/`。保存前严格校验请求、真实编码格式、尺寸和哈希，单文件上限256 MiB。升级前备份失败保持旧库不变；伪装为旧格式的新数据拒绝加载。复制迁库改写托管路径，合并处理作品 / 工程 ID 和照片关联冲突，完整备份带走图片及快照。仅复制数据库不足以恢复图片。

失败只清除确定未发布的本次候选文件，不删除不确定提交状态的资产。切库后迟到的写入不能进入新库。输出没有后台云调用、自动重试或原片写入；PNG/JPEG/WebP 保持前述元数据与颜色输出边界。批量部分成功可继续保留，不能把未保存页标成成功。

## 六套精选预设（2026-10-28）

Windows 和浏览器端新增共同的预设入口：画廊留白（1:1）、双页叙事（3:2）、胶片连拍（3:2）、旅行手记（4:5）、杂志主图（4:5）、方格集锦（1:1）。每套包含布局、比例、背景、间距、留边和圆角；预览插画由本项目 SVG 绘制，几何与实际输出共用坐标。不是额外下载的模板图片。

空白拼图先选择样式，添加照片后自动套用。已有拼图一键更换样式时保留全部照片、顺序及各自的取景，使用原撤销/重做入口恢复。六套均按 1–12 张照片自动选择原有 80 种布局之一，不复制或丢弃原片。更多照片仍使用批量拼图；预设可应用到全部页面，余图页按其实际数量适配，重新分组保留统一预设。单页修改成自定义样式后不会被错误标为统一预设。

预设写入普通版本 2 拼图配置，没有新增数据库或清单格式。保存工程、下载清单、重新选择原片、恢复作品、PNG/JPEG/WebP 导出沿用已有实现。预设名称不会盖过已保存的真实画布配置；以后修改预设也不会改变旧作品。默认画布和输出格式偏好不被预设选择覆写。

设计参考 AfterFrame 已获 MIT 授权的布局，以及 [Adobe Express 的拼图网格与边距工作流](https://www.adobe.com/express/create/photo-collage)、[Canva 拼图模板的极简、网格、纸面结构](https://www.canva.com/photo-collages/templates/) 和 [photo-strip 结构](https://www.canva.com/templates/s/photo-strip/)。本项目自行设计配色与完整样式参数，不复制这些站点的照片或模板资产。
