# 导入后本地人物分析（融合开发分支）

Windows 桌面和连接本机服务的网页在“设置 → 导入后人物分析”提供独立开关，默认关闭，修改立即保存到当前图库。原人物页的手动分析、分组检查、确认、影集和撤销入口保留。独立浏览器图库尚无本地人物引擎，不显示这个开关，也不会改用云端人脸接口。

## 开启以后

只有在开关开启时开始的导入，才会为这次真正新增的照片记录排队。目录扫描、路径导入和文件上传使用同一策略。同内容重复、重新定位已有原片、补齐旧预览都不算新增；上传返回的全部照片 ID 与自动分析的新 ID 单独收集，避免重复照片误入任务。

元数据和预览按原流程完成，人物分析是独立的本地任务，不占用导入的 I/O 队列。多个导入分别保留自己的有限 ID 集合，在已有本地推理队列中串行执行，不以整库补扫代替遗漏任务。已有识别缓存、人工确认、忽略决定和人物影集快照继续由原人物服务保护。

自动模式沿用人物服务默认的 **0.45** 相似度阈值。新结果是待人工确认的建议，不自动确认身份或创建人物影集。

RAW/JPEG 沿用按拍摄分组：只分析本次新增且仍是当前优选文件的记录。新增 RAW 若与已有 JPEG 配对而不是优选文件，跳过它，不擅自把旧 JPEG 加入这次任务。排队期间已移出图库的记录也跳过，不重新登记原片。

## 模型、停止与失败

只使用已准备好的 YuNet/SFace 本地模型。开关本身不下载模型，不读照片，不上传照片或调用付费服务。模型未准备好时，照片正常导入，任务详情说明可稍后手动分析；准备模型不会自动补扫旧照片。已有识别占用模型时，导入和开关操作不等待模型锁，人物任务排队后再检查。

关闭开关会取消排队或正在执行的自动任务；正在计算的结果在保存前再次核对开关、图库和取消状态。已保存的识别结果保留，原手动人物任务不被取消。关闭后再开启也不会恢复此前正在导入但尚未排队的授权。重启后的未完成任务沿用“已中断、手动重做”，不自动续跑。

活动中心里，导入任务详情显示已安排分析、没有新增照片、模型未就绪或队列不可用。已排队时可点“查看本次人物分析任务”，查看独立的成功 / 跳过 / 失败与取消。人物分析失败或队列已满不把已经完成的照片导入标为失败，不自动重试；需要时到人物页手动分析。

策略保存在现有设置文件，不增加数据库迁移；SQLite schema 14、独立浏览器 manifest 10 保持。所有派生观察继续绑定当前模型来源，原片只读。

## 验证

隔离合成库检查默认关闭、严格布尔开关、偏好保存、重复 / 重新定位 / 部分失败与上传去重、模型未就绪、队列故障、手动 / 自动任务隔离、关闭排队与运行中任务、阻止迟到结果、导入时开启及关闭再开启、模型锁忙碌和排队后删除 / 优选变化。受控本地识别只用于验证流程，不作为真实识别准确率结论；原片 SHA-256 保持。
