# 水彩转绘：2.6.0 千问版使用说明

更新日期：2026-10-16。当前应用版本：2.6.0。开发分支：`codex/windows-watercolor-2.6.0`。

## 已实现

- 侧边栏和照片详情中的「水彩转绘」入口；页面地址 `/watercolor`，可直接刷新打开。
- 从照片库选图，手动输入标题，或将照片与拍摄时间发送给千问获取标题建议。关键词可补充地点；不自动认定视觉猜测的地点，不发送 GPS。候选标题必须确认后才用于生成。
- 单图与 Windows 批量水彩转绘，独立后台任务、取消与失败提示。页面只恢复正在执行的任务，不再反复显示旧 OpenAI 等历史失败；中断任务不自动重新计费，新一次生成保留旧作品。
- 本地象牙白纸面、默认 55% 或参考图约 85% 版式、纸纹及已有中文/英文艺术字字体。确认后的标题由本地文字渲染器绘制；保存标题来源与候选依据。
- 原片、转绘场景、海报预览及原片/场景滑杆对比；作品列表、再次排版、删除及 PNG/JPG 导出。作品默认自动保存；本地排版修改需要点击保存。
- 独立作品记录与派生目录，自动扫描排除，库迁移包含作品与加密凭证。删除作品保留原图和已导出文件。删除原照片的库记录后仍可编辑已保存的作品。
- 中英文、明暗主题与窄屏布局。原图保持只读，输出文件名冲突时另存新文件。
- 已保存的水彩海报可发送到水印工坊，使用现有水印样式、预览与导出。水印草稿固定使用发送时的海报版本，并保留原照片的拍摄参数；之后修改水彩标题或排版不会改变已有水印草稿。

## 如何使用

1. 安装 Windows 2.6.0，或运行此开发分支的应用（例如项目根目录的 `start.cmd`），打开「水彩转绘」。旧版本需要安装新包才会获得此修改。
2. 打开「AI 服务设置」，填写此千问接口对应的 API Key。Windows 使用当前用户的 DPAPI 单独加密保存；其他平台通过启动环境变量 `DASHSCOPE_API_KEY` 提供。环境变量优先于本机保存的密钥，页面会显示该状态。旧版 OpenAI 密钥不会被复用，也不会发送给千问，升级后需要配置千问密钥。
3. 「图像模型」提供 `qwen-image-3.0` 和 `qwen-image-3.0-pro` 两个选项，选择后点击「保存设置」。默认标准版；Pro 的接口模型名包含 `-pro`。标题建议默认使用 `qwen3-vl-plus`，需要该接口的视觉模型权限，可更换为账户支持的千问视觉模型；没有此权限时可手动填写标题。设置保存只保存配置，不会发出生成请求，也不代表已验证余额或模型权限。
4. 选择照片。输入标题或展开「从画面建议标题」，选择候选后勾选确认；也可留空并确认不加标题。
5. 选择版式与质量，点击「生成水彩海报」。该步骤明确上传选定照片，可能产生 API 费用；标题建议也是单独一次云端请求。
6. 比较原片和实际转绘结果。改标题、字体、纸纹或留白比例后保存排版，再导出；这些排版操作仅在本地执行。
7. 需要水印时，保存排版后点击「发送到水印工坊」。水印预览和导出均以这张已保存的海报为来源。需要采用新版海报时，再发送一次；删除水彩作品前须先删除引用它的水印草稿。

### Windows 批量创作

1. 点击「上传照片」一次选择多个文件，或点击「选择照片」在图库中多选并确认，每批最多 100 张。上传只复制到本机照片库，不会立即发送给 AI；相同内容去重。
2. 确认缩略图、版式、纸纹与质量。批量作品先按无标题海报生成。
3. 如需 AI 标题，勾选「图片生成后逐张生成并应用 AI 标题（可选）」，可填写共同关键词；默认关闭。
4. 点击「生成 N 张水彩海报」才开始付费请求。队列先逐张生成全部图片并保存，再为成功作品逐张请求标题并应用第一条建议。标题来源与依据随作品保存，之后仍可手动修改。
5. 页面显示图片和标题阶段进度及每张结果。单张生图失败会继续处理其余照片；标题失败保留无标题作品。取消会停止后续请求，已提交的请求可能仍会计费，已保存作品保留；无自动重试。

批量任务在本机后台执行，切换页面后可恢复查看进行中的任务。关闭应用会中断任务，已保存作品仍在「水彩作品」中；重新打开不会自动再次请求。

本版本采用用户指定的接口 `https://maas.qianwenaiapi.com/api/v1/services/aigc/multimodal-generation/generation`，设置窗口会显示地址。请使用该接口服务对应的密钥；不会自动切换到阿里云其它区域地址。

生成同时发送经过缩放且移除 EXIF/GPS 的原图和转绘指令。草图关闭提示词优化；标准启用优化并关闭模型思考；精细同时启用优化和思考。每次只生成一张，关闭服务水印。云端返回图片会立即下载并保存到本地，再进行海报排版。

导出目录沿用软件中的存储设置。数据库备份接口仍只备份数据库；要完整备份作品，需要同时保存 `DATA/artworks/`。`qwen-art-key.dpapi` 是当前 Windows 用户保护的千问凭证，库迁移会包含此文件；换电脑或换用户后可能需要重新填写，不能视为可跨设备使用的密钥备份。

## 实现边界

当前源码包含单图转绘、Windows 批量转绘、本地排版与水印工坊联动。Windows 桌面与本机网页版共用批量流程；未新增本地 GPU 转绘、多供应商或地理编码服务。旧版安装包需要升级后才会获得这些改动。

真实图像质量尚未验收：测试中的生成服务使用模拟响应，界面截图使用明确的几何场景测试图，不代表真实水彩效果。需要用户配置可用的 API Key 后，以人像、建筑和风景样片验证主体数量、边缘主体、透视、自然水彩边缘与颜色。模型可能修改细节，不能保证逐个主体完全一致。

输出保留原片宽高比（整数像素舍入除外），最长边不超过 1536 像素且不超过原片最长边。超长画幅先添加技术留边以适配图像服务，再仅按已知位置移除留边；若服务返回尺寸不符则提示失败，不通过拉伸或裁掉主体掩盖错误。纸面版式在标题空间不足时会自动缩小完整插画；长标题缩小字号，不截断内容。

协议依据：[千问图像生成与编辑](https://www.alibabacloud.com/help/en/model-studio/qwen-image-generation-and-editing-api-reference)、[千问视觉模型 DashScope 调用](https://www.alibabacloud.com/help/en/model-studio/multi-round-conversation)。这些文档用于核对请求与响应格式；用户提供的网关是否开放对应模型，以实际账户权限和请求结果为准。
