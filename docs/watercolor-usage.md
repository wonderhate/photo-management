# 水彩转绘：首轮实现与使用

日期：2026-10-13。开发分支：`codex/ai-watercolor`。

## 已实现

- 侧边栏和照片详情中的「水彩转绘」入口；页面地址 `/watercolor`，可直接刷新打开。
- 从照片库选图，手动输入标题，或将照片与拍摄时间发送给 OpenAI 获取标题建议。关键词可补充地点；不自动认定视觉猜测的地点，不发送 GPS。候选标题必须确认后才用于生成。
- 单图水彩转绘，独立后台任务、取消与失败提示，重启后恢复任务记录。没有自动计费重试。新一次生成保留旧作品。
- 本地象牙白纸面、默认 55% 或参考图约 85% 版式、纸纹及已有中文/英文艺术字字体。确认后的标题由本地文字渲染器绘制；保存标题来源与候选依据。
- 原片、转绘场景、海报预览及原片/场景滑杆对比；作品列表、再次排版、删除及 PNG/JPG 导出。作品默认自动保存；本地排版修改需要点击保存。
- 独立作品记录与派生目录，自动扫描排除，库迁移包含作品与加密凭证。删除作品保留原图和已导出文件。删除原照片的库记录后仍可编辑已保存的作品。
- 中英文、明暗主题与窄屏布局。原图保持只读，输出文件名冲突时另存新文件。

## 如何使用

1. 运行此开发分支的应用（例如项目根目录的 `start.cmd`），打开「水彩转绘」。**此前安装的 Windows EXE 尚未重新打包，不会自动获得这次修改。**
2. 打开「AI 服务设置」，填写自己的 OpenAI API Key。Windows 使用当前用户的 DPAPI 加密保存；其他平台通过启动环境变量 `OPENAI_API_KEY` 提供。环境变量优先于本机保存的密钥，页面会显示该状态。
3. 默认图像模型为 `gpt-image-2`，标题建议模型为 `gpt-4.1-mini`；账户是否可用以实际请求为准。设置保存只保存配置，不会发出生成请求。
4. 选择照片。输入标题或展开「从画面建议标题」，选择候选后勾选确认；也可留空并确认不加标题。
5. 选择版式与质量，点击「生成水彩海报」。该步骤明确上传选定照片，可能产生 API 费用；标题建议也是单独一次云端请求。
6. 比较原片和实际转绘结果。改标题、字体、纸纹或留白比例后保存排版，再导出；这些排版操作仅在本地执行。

导出目录沿用软件中的存储设置。数据库备份接口仍只备份数据库；要完整备份作品，需要同时保存 `DATA/artworks/`。`art-key.dpapi` 是当前 Windows 用户保护的凭证，换电脑或换用户后可能需要重新填写，不能视为可跨设备使用的密钥备份。

## 实现边界

此次交付是计划中的首轮单图功能。尚未新增水印工坊的作品来源联动、批量生成、本地 GPU 转绘、多供应商或地理编码服务。源码和本地前端构建已更新，尚未合并 main、推送 GitHub或重新发布安装包。

真实图像质量尚未验收：测试中的生成服务使用模拟响应，界面截图使用明确的几何场景测试图，不代表真实水彩效果。需要用户配置可用的 API Key 后，以人像、建筑和风景样片验证主体数量、边缘主体、透视、自然水彩边缘与颜色。模型可能修改细节，不能保证逐个主体完全一致。

输出保留原片宽高比（整数像素舍入除外），最长边不超过 1536 像素且不超过原片最长边。超长画幅先添加技术留边以适配图像服务，再仅按已知位置移除留边；若服务返回尺寸不符则提示失败，不通过拉伸或裁掉主体掩盖错误。纸面版式在标题空间不足时会自动缩小完整插画；长标题缩小字号，不截断内容。
