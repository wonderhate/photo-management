# 多图对比（融合开发分支）

在图库选择 2–4 张照片，点击“对比”进入独立页面；既有 `/compare?ids=…` 链接和本地 Web 的 `/#/compare?ids=…` 保留。每张照片继续显示文件名、相机、镜头、曝光、拍摄时间及尺寸。移除只改变本次对比列表，少于两张时返回图库，不删除照片记录或原片。

## 同步与单独调整

默认开启“同步视图”，沿用原来同时缩放多张照片的操作。缩放范围为适应窗口大小的 50%–800%，加减按钮和滚轮均可用；100% 在这个页面表示每张照片各自适应窗口的大小，和单图查看器的“实际预览像素”不同。

放大后可用鼠标、触摸拖动，或聚焦图片区域后按方向键移动；按住 Shift 使用较大步幅。滚轮以指针为中心缩放。同步传递相对缩放和画面内的归一化观察位置，因此不同尺寸、横竖构图仍保留原比例。每张图片分别限制边界，某一方向未超出窗口时保持居中；不会为了联动而拉伸图片或露出越界空白。

关闭“同步视图”时，各图保留当时的位置，可分别调整。点击照片、聚焦图片区域或点击文件名可指定当前操作照片；顶部工具作用于该照片。重新开启同步时，其他照片跟随当前照片的观察位置。

“居中对齐”保持缩放，只将画面中心对齐；“适应窗口”恢复完整画面。同步开启时同时作用于各图，关闭时只调整当前照片。这是按图像位置对齐，不是基于特征点的自动透视或内容配准。

## 文件和资源

对比继续读取已有预览，使用共享媒体租约，不新增原片解码、工程内容、导出或 AI 请求。本地 Web 新增只读的对比查询，修复原入口缺少本地数据路由而无法显示照片的问题；不会请求服务端上传。请求只包含最多四个唯一照片 ID，按选择顺序显示。切换深链接或离开页面取消旧查询，旧响应不会覆盖新列表。

宽屏保持并排 / 多格，窄屏纵向排列；主题颜色沿用当前变量，无新增持续动效。工具可通过键盘操作，删除键不会从对比页移除图库照片。

## 当前验收

新增检查覆盖横竖图的实际像素比例、联动观察位置、独立调整和重新连接、居中 / 适应、键盘焦点、2–4 张移除、深链接和迟到请求。本地 Web 使用实际授权文件和预览，含真实 CDP 触摸拖动，逐一核对三张合成原片哈希和返回图库后的记录数量。宽屏中文暗色和窄屏英文浅色截图已人工核对。
