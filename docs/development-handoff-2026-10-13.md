# 光影集开发交接与后续优化

整理日期：2026-10-13。当前应用版本：**2.5.1**。当前阶段功能开发到此结束；后续从最新 `main` 建立新功能分支。本文件整理整个过程、最终范围、架构、数据约束、验证与优化顺序。

## 1. 最终产品范围

提供 Windows 桌面与本机网页版，共用 React 界面和 FastAPI 后端。Windows 用 WebView2 展示本机服务，不是另写一套业务。

保留照片管理、EXIF、影集、时间线、器材统计与摄影报告、对比、本地语义搜索、人物分组、水印草稿与导出、艺术字署名、水彩转绘、主题与目录设置。

Android、iOS、手机配对、远程访问和公网地址管理均已取消。窄屏布局用于本机网页体验，不代表仍有手机客户端。旧 Express 原型已移除。历史记录中出现的这些功能不属于待恢复要求。

水彩可选 `qwen-image-3.0` / `qwen-image-3.0-pro`，Pro 的规范名称含 `-pro`。初版 OpenAI 已替换。暂不提供批量水彩、多供应商、离线 GPU 转绘或自动地理编码。

## 3. 已交付工作流

### 照片、计数与影集

路径导入计算 SHA-256、读取 EXIF 并生成派生预览。同内容去重，换位置后可重新定位。RAW / JPG 按目录、文件名主体和元数据一致性分组；歧义时不盲目配对。默认按拍摄计数，可切换为文件计数。

普通影集支持封面和排序，智能影集利用本地向量和人工确认候选。人物分组用本地 OpenCV / SFace，命名并确认后创建影集，已有影集直接打开。人物影集是普通影集快照，之后分组变化不自动重写成员。

### 水印与署名

摄影相框、沉浸光感共用预览和最终渲染。草稿保存配置与预览，正式导出单独触发。支持恢复、复制、撤销 / 重做、未保存提醒与状态筛选；批量导出保留每份草稿自己的参数。

艺术字使用本地字体及授权文本。常用中文和拉丁字符可编辑，缺字回退；原创 wonder 图片是固定图案，不能任意改字。

### 水彩

选图 → 输入标题或请求建议 → 用户确认标题 / 不加标题 → 选择模型和质量 → 原图与指令转绘场景 → 本地纸面和标题排版 → 保存、导出或发送水印工坊。

目标是细墨线、透明水彩、克制手工瑕疵、象牙白纸纹和大量留白。默认插画宽度 55%，参考版式约 85%；保留原片主色与光照，不强加日落、蓝紫或桃粉。

画布保持原片比例，长边不超过 1536 像素且不超过原片长边。极端比例用技术留边，只移除已知留边。服务返回尺寸不符则失败，不能裁主体或拉伸补救。标题本地精确绘制；修改字体、标题、纸纹和留白不再调用生成。

水印固定引用发送时的 `poster-N.png`；之后修改水彩不改变旧草稿，需要新海报时重新发送。删除原照片库记录后已保存水彩仍可用；有水印引用时阻止删除对应水彩。

## 5. 数据、凭证与不可变约束

- 原始照片只读，删除整理记录不能删除或覆盖原片。浏览器上传副本在 `imports/`，区别于路径登记的外部原片。
- Photo、拍摄分组、Album、人物 / 人脸、WatermarkDraft、Artwork、Job 是主要对象，不用页面内存代替持久关系。
- 水彩保存 `scene.png`、`poster-N.png`、`preview-N.webp`。旧海报保留给水印引用，目前没有版本垃圾回收。
- 导出冲突自动编号，可下载范围由导出登记维护，不能开放整个 Downloads 或任意磁盘路径。
- Windows 默认库在 `%LOCALAPPDATA%/PhotoCollection/data`。环境指定路径优先于配置；目录修改重启生效，旧库和外部原片保留。
- 数据库备份不是完整作品备份。关闭应用后保存托管文件；外部原片、历史自定义导出和模型缓存单独保存。
- `qwen-art-key.dpapi` 与 Windows 用户绑定，库迁移包含它，跨用户 / 电脑可能无法解密。`DASHSCOPE_API_KEY` 优先；旧 OpenAI 环境变量和凭证不读取。
- 导入、搜索、人物、水印和本地排版不上传照片。水彩和标题建议是用户显式云端请求，移除元数据、不发送 GPS。
- 不能恢复开放公网监听。容器内部监听与宿主发布分开，宿主仍绑定回环地址。

## 6. AI 协议与质量边界

固定使用用户提供的 `https://maas.qianwenaiapi.com/api/v1/services/aigc/multimodal-generation/generation`，按 DashScope 协议接入，未将此域名认定为阿里云官方域名。账户、模型、Key 必须匹配该服务，不自动改用其它区域。

请求含原图 Base64 与一条转绘指令，一次一张、关闭水印。草图关闭提示词优化；标准启用优化；精细增加模型思考。标题建议默认 `qwen3-vl-plus`，需要网关支持，否则手动填写。

按返回结构和尺寸验证图片，再本地保存。下载不附带 API 授权头、不跟随重定向，目前仅接受网关 / 阿里云对象存储 HTTPS 和图片 Base64。服务若改用其它 CDN，需要明确扩展受信任来源，不能放开本机 URL。

错误按已知代码区分余额 / 配额、限流、密钥、模型参数，不直接展示响应正文。目前无独立账户联通验证、费用预估、请求 ID 查询入口或自动重试。

**真实千问画质尚未验收。** 已验证模拟协议、合成图和本地流程，没有上传私人照片或调用付费生图。未来需用明确获准的风景、建筑和人物样片，比较主体数量、服装颜色、边缘主体、透视、光线和水彩边缘。模型不保证每个细节绝对一致。

## 8. 整理与发布规则

本次更新 README、CHANGELOG、CONTRIBUTING、AGENTS、文档索引及 Issue / PR 入口；历史验收集中在 `docs/history/`。废弃 Express、旧调试 / 测试入口和失效外站截图分析从当前树移除，Git 历史保留。

个人素材转入忽略的 `.local-notes/`。真实照片库、模型、正在运行的进程目录和其它 Git worktree 不清理。最新发布确认后可移除重复的旧本地安装包，保留当前安装、便携及校验文件。

主分支普通快进 / 合并，不强推。Release 的源码标签、安装包、ZIP、校验和说明必须对应；最终发行以 Release 的 `SHA256SUMS.txt` 为准，不能拿历史旧哈希核对重新构建的包。

容器自动构建验证，主分支手动运行 `Web package` 才发布。Windows Release 不自动替换镜像，查看实际工作流 / Package 状态，不凭 README 推定镜像已公开。

保留字体 OFL、版权文本和品牌来源。源代码许可证由作者决定，本次不自行增加授权。

## 9. 后续优化顺序

| 优先级 | 工作 | 完成标准 |
| --- | --- | --- |
| P0 | 千问真实样片验收 | 获准样片与有效账户；两模型各测横、竖、人像、建筑、长画幅；记录耗时、尺寸、主体变化与可接受效果 |
| P0 | 账户错误诊断 | 安全错误分类和请求标识；分开余额、限流、参数、下载失败；不泄密或自动重复计费 |
| P1 | 比例和留边鲁棒性 | 核对服务实际尺寸取整、极端比例、失败恢复，完整主体不被裁切 |
| P1 | 水彩版本空间管理 | 根据水印引用清理未使用版本；提供空间提示，不删除在用海报 |
| P1 | 发布可复现 | CI、实际 EXE、安装升级保留库；README / Release / Packages 无版本错位 |
| P1 | 备份 / 恢复 | 明确元数据与完整库备份；跨盘、中断、缺失原片、DPAPI 失败均可恢复 |
| P2 | 大库性能 | 隔离 50000+ 文件，记录导入、筛选、分页、搜索、报告指标，按热点优化 |
| P2 | 字体与英文 | 长标题、罕见字、回退、长路径和全部英文错误，避免新增硬编码中文 |
| P2 | 本地模型交付 | CPU / GPU、首次下载 / 离线、损坏 / 版本变化，失败不阻塞基础操作 |

批量生图、第二供应商、离线生成和已取消平台需先有明确新需求，不能从历史计划自动恢复。
