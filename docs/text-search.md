# 全文搜索与本地文字索引（融合开发分支）

照片页的搜索框可选择「全部文字」或「文件名」。全部文字查询文件名、相机品牌 / 型号、镜头、当前有效标签、当前描述与已经保存的识别文字；不读取照片像素，不发起 AI 调用。大小写忽略，输入的 `%`、`_`、引号、`OR` 都按普通文字处理。

## 搜索方式

| 方式 | 查询对象与运行位置 |
| --- | --- |
| 全部文字 | Windows / 本机服务与独立本地网页版共同支持；查当前保存的文字子串 |
| 文件名 | 两端共同支持，仅匹配文件名，忽略大小写 |
| 自然语言 | 本机服务保留既有日期、器材等规则解析；剩余画面描述交给本地视觉语义模型 |
| 画面语义 | 本机服务使用既有 Chinese-CLIP / FAISS，按画面相关性召回，不由文字索引代替 |

本机服务默认保留自然语言方式，独立网页版默认全部文字。独立网页版没有本机模型服务时禁用自然语言和画面语义选项。模型未加载时提示加载并保留已有查询；稍后返回的解析不能覆盖更新的查询或其他页面。

中文单字、词和短语都可查询。文字搜索不会把「海岸」自动扩展成「海边」；这类相近画面表达由独立语义检索处理。现有影集、标签、评分等筛选与新文字条件取交集，数量、ID、分页和统计沿用同一查询规则。

人工描述优先于 AI 描述。人工明确留空时，全部文字不会搜索被覆盖的 AI 描述；删除或拒绝的 AI 标签也不会因原始标注中仍有该词而再次成为全文命中。OCR 文字单独保留，不因描述留空而隐藏。此阶段只查询已有标注，自动识别与模型质量由后续 AI 功能验收。

## 条件集合

条件编辑器新增「全部文字」「当前描述」「人工描述」「AI 原始描述」「识别文字」字段，以及「包含（忽略大小写）」。原「包含文字」仍区分大小写。「AI 原始描述」允许明确查阅被人工覆盖前的模型记录，不改变默认全文的人工作主规则。

空字符串和缺失值继续分别判断：人工描述可以明确为空；经过清理的当前描述为空时按未设置处理。NOT、AND、OR、日期、评分、现有语义交集仍使用同一个有界 QueryAST。查询值上限为 256 个 Unicode 码点。

## 文字索引与维护

本机服务使用 SQLite FTS5 trigram 加速元数据子串候选，然后用当前权威元数据逐项复核。短于三个字符、部分 Unicode 大小写以及索引不可用时直接按当前文字匹配。这样的回退符合 [SQLite trigram 的短词限制](https://sqlite.org/fts5.html#the_trigram_tokenizer)，不会把短中文查询变成无结果。

索引、稳定行号映射和待处理队列均为可重建的本地派生数据。照片、标签或标注更新时只将相关 ID 标为待处理；搜索同时覆盖尚未更新的记录，旧索引不会遮挡刚保存的信息。后台每批最多处理 256 条元数据，不打开原图或预览。删除记录会清理对应索引，仍保留原片。

设置页「文字索引」显示已索引数量、待处理数量和任务状态，可主动建立 / 修复。索引覆盖缺失时回退，并提示重建；重建不改变描述、标签或照片。该任务复用已有本地 I/O 队列，可取消，不计费。新增元数据不断变化时，下一次查询继续补齐剩余队列。

独立网页版直接查询本地清单，不使用 SQLite，不假装具有 FTS 或视觉模型。更大的浏览器索引与性能预算继续由后续对应条目验收。

## 兼容与验证

AF23 引入时的格式为 SQLite **schema 10** / browser **manifest 9**。SQLite 10 保留既有照片字段，升级前备份；版本门槛保护使用新搜索条件的集合。浏览器可读旧 1–8；首次写入先把旧清单完整字节存为 `library.before-text-v9-*.json`，原有阶段备份仍保留。备份失败不发布新清单。未知未来格式、旧格式冒用新字段或 `icontains` 运算符均拒绝写入。

共享合成向量分别验证中文词、短语、大小写、字面特殊字符、人工空描述、明确查询 AI 原始描述、OCR、有效标签及布尔组合。语义同义表达使用受控召回验证原路线及交集；它不能证明真实模型质量。另有真实 FTS 查询计划、一万条纯元数据分批、事务回滚、索引缺失回退、主动重建、旧清单升级及中英文宽窄屏检查，使用合成原片并核对 SHA-256。当前完整回归结果见[融合实施记录](afterframe-upgrade.md)。

当前格式随[本地人物模型保护](face-model-spaces.md)与[人物整理](person-management.md)及[连续切图保存基础](seamless-split.md)更新为 SQLite **16** / browser **12**，可读旧清单 1–10，原全文与标注字段保持。
