# 本地主体、深度与混合图层

这是 AfterFrame 融合开发分支的能力，验收状态以 `afterframe-upgrade-plan.json` 为准。

## 使用

数字暗房保留原来的照片调整、裁剪、文字和蒙层。打开「本地贴纸库」可导入透明 PNG，或把「本地主体与深度」的分割结果加入当前工程。素材保存在当前图库；隐藏素材只影响素材列表，已有作品仍能读取它。透明 PNG 可单独导出。

文字、贴纸、纯色及渐变蒙层共享排序、显隐、锁定、复制与撤销。贴纸支持描边、阴影、发光和透明度。画布提供八个缩放手柄、旋转圆点与方向键移动；Shift 保持角点缩放比例或约束旋转角度，Alt 临时关闭吸附，Esc 撤销当前手势。缩放独立保存为横纵比例，不会改写文字字号。旋转手柄与缩放手柄保持屏幕间距。

模型不会自动下载。展开「离线模型」，阅读许可，从界面给出的固定版本链接获取列出的全部文件，再导入。文件大小与完整 SHA-256 必须匹配。模型权重不放入 Git、安装包或照片库备份；换设备须重新准备模型。没有模型仍可使用普通编辑和 PNG 贴纸。

在原图选点区为一个主体添加保留点和排除点，必要时调整羽化。支持最多八个主体，每个主体最多32点，每个主体独立生成 PNG。结果不会自动覆盖原图或已有图层。

深度模型生成相对远近蒙版。选中文字或贴纸后，选择「将所选图层置于主体后方」，再调节阈值、过渡羽化和反转。它不是精确距离测量；透明物、镜面、复杂头发和细小结构需要检查。

## 两种运行时

| 项目 | Windows / 本机服务 | 纯网页本地图库 |
| --- | --- | --- |
| 深度 | Depth Anything V2 Small，Transformers / PyTorch CPU | 同系列量化 ONNX，Transformers.js / ONNX Runtime WASM |
| 主体 | SlimSAM uniform-50，PyTorch CPU | SlimSAM 77-uniform，量化 ONNX / WASM |
| 安装 | 逐文件校验后原子安装本地包 | 逐文件校验后保存 IndexedDB |
| 网络 | 离线模式、只加载本地 safetensors，不执行远程模型代码 | 禁止远程模型加载，WASM 随应用提供 |
| 取消 | 终止独立推理子进程 | 终止推理 Worker |
| 边界 | 输入预览最长边2048；任务超时300秒 | 相同输入尺寸与超时；单线程 WASM |

四个模型包均固定 revision、文件清单和 SHA，详见 `backend/app/vision_models.json` 与前端同名清单。两个分割运行时使用不同压缩版本，不能承诺逐像素相同。CPU / WASM 的实际耗时受图片、设备、内存与浏览器影响。

SAM 输出的是前景分类 logit，并非精确透明度。实现将零阈值附近的一小段平滑映射到 alpha，其他区域截为全透明或不透明，再按用户选择羽化；直接对全部 logit 做 sigmoid 会留下背景残影。这个转换不等于专业毛发抠像：样片中的服装反光、头盔和局部背景可能仍需增加排除点或保留点。

人工边缘检查使用 NASA 的公开宇航员样片，未使用私人照片。来源与公共领域说明见 [scikit-image astronaut 文档](https://scikit-image.org/docs/stable/api/skimage.data#skimage.data.astronaut)。样片和检查图只在忽略的测试目录，不作为产品素材。自动回归使用合成照片。

## 保存与渲染

新工程使用 Recipe v4 / LayerDocument v2；旧配方和旧图层仍可读取。v2 冻结添加图层时的源尺寸、裁剪、旋转与翻转坐标，后续裁切通过矩阵映射，预览与最终导出共用渲染器。LUT 和照片调整先执行，文字、贴纸与蒙层随后按同一堆栈顺序合成。

素材 PNG 按内容 SHA 存储并复核。深度引用同时绑定原片 SHA；不能把另一张照片的深度图套入当前工程。深度缓存还绑定输入像素与模型版本。迁移、完整备份、工程引用和旧素材恢复沿用既有图库机制；隐藏不是删除。

图层折叠、吸附和素材显示偏好按图库保存，作品文字、位置、样式与深度参数保存在工程，不存入全局偏好。模型许可确认、AI计费确认和令牌不作为偏好恢复。

当前验证范围包括真实离线 CPU / WASM 推理、透明度与混合顺序像素、原片哈希、保存重开、八向手柄及中英宽窄界面。具体结果以批次记录为准；不替代安装包、所有相机和所有硬件的发行验收。
