## 尚未通过的验收边界

Codex 内置浏览器返回“saved browser permissions could not be verified”，拒绝本地页面访问。未绕过此安全检查，也未通过另一自动化入口伪装成真实浏览器验收。

用户保存浏览器权限后再次尝试，仍返回同一校验失败；网页验收尚未通过，需要恢复应用浏览器权限校验后继续。

恢复浏览器权限后，必须完成：各导航和移动布局、虚拟滚动与快速筛选、真实文件选择器/拖拽、主题/部分英文/快捷键、影集拖动、水印滑块/预览、首次保存/自动保存/退出提醒、重启恢复、批量导出面板以及人物分组交互。

`frontend/tests/` 的现有网页脚本需要按实际测试地址与最新界面复核后运行。页面 HTTP 200、API 与逻辑测试通过都不能替代上述交互验收。
