# 媒体引用、缓存与本地下载

此说明对应融合开发分支。图库继续按 ID 取得可见窗口的照片元数据，四种布局使用虚拟列表／几何窗口；照片卡片不会因一次后台刷新而整页重建。当前照片元数据缓存上限为 600，单次读取最多 200 条。ID 和布局几何仍随图库规模增长，不能据此宣称任意大库的总内存恒定。

## 图片租约

独立浏览器的缩略图、标准预览、水印草稿预览、水彩场景和海报共用 `ResourcePool`。实际显示时才读取文件并创建 Blob URL，离开可见区域或卸载组件时释放引用；同一文件的多个显示位置复用同一资源。加载并发为 2，空闲缓存按最近使用回收，总条目预算 256、压缩文件字节预算 96 MiB。正在显示的引用不被淘汰；活跃资源本身可能超过空闲预算，释放后再回收。

96 MiB 统计文件／Blob 字节，不是浏览器解码位图、GPU 或整个应用的内存上限。按需高清显示另沿用既有 12 项／48 MiB 缓存，编辑器的工作源与显示预览分离。查看器只对稳定停留的当前照片和少量相邻照片做延迟预读，关闭或快速切换会取消旧工作。

此前独立浏览器的草稿、海报和导出链接在读取列表时就创建 Blob，并一直保留到关库。现在这些列表只返回带图库 UUID 和本次打开会话的本地引用，不打开图片或导出文件。启动任务面板也先读取摘要，再读取选中的一个任务，避免同时展开所有历史导出结果。显示中的图片仍有租约，回收其他缓存不会使它失效。

## 本地文件链接

`/_pc-file/<会话>/<图库>/<派生路径>` 是当前应用标签页内的文件引用，并不是服务器上公开的下载目录。允许的路径限于照片缩图／预览、草稿预览、水彩场景／版本海报及已导出的图像；原片、清单、密钥、编辑工作源和任意磁盘路径不在此接口范围。

离线服务收到此地址的请求时，只向发起请求的窗口询问文件。窗口再次核对图库 UUID、会话、目录和代次，读取已经授权的本地文件；关闭或切库后的旧引用返回不可用，新标签页也不能借旧窗口的链接读取文件。服务脚本不保存文件句柄、文件或 Blob URL，响应使用 `no-store`，不进入离线 CacheStorage。支持普通读取、单一字节范围和无效范围错误。

普通离线脚本与浏览器生产构建生成的脚本使用同一文件响应实现，生产缓存版本也计入这段实现的内容。没有单独的照片 HTTP 服务、网络上传或新增远程访问入口。

## 下载与关闭图库

用户点击水彩、水印、任务结果或暗房导出时，读取当前会话内的导出文件，再触发原有下载行为。只在明确下载期间临时持有一个文件 Blob URL，60 秒后撤销；关闭图库会撤销本窗口剩余引用。导出文件本身仍在图库 `exports` 中，恢复历史任务后可重新取得下载引用，缓存回收不会删除文件或使这个入口丢失。

最近操作继续打开该批导出的第一个文件，其余结果可在任务面板或活动中心查看。新的最近记录只保存图库身份、首个文件的稳定位置和任务 ID，不保存 Blob URL 或进程会话参数。打开时先核对当前图库，再取得新的引用；任务历史已回收时，只要文件仍在对应图库中仍可打开。本机服务地址重新绑定当前进程会话，浏览器由当前授权窗口读取文件后交给新标签页显示，不让新窗口直接访问旧窗口的文件接口。

带图库身份的旧本地文件地址仍可转换；无法核验身份的过期旧记录不会猜测当前同名文件，可从活动中心或原导出目录查找。坏格式的最近操作数据不影响其他界面。切到另一图库时，打开对应记录会明确提示，不读取那里的同名文件。

图片显示和点击下载也直接支持本地文件读取。因此离线服务被禁用时，当前窗口内的图片和下载按钮仍然可用；直接通过 `fetch` 访问上述文件地址需要正常工作的离线服务。开发页面同样应使用应用提供的图片与下载组件。关闭／重开图库后需从当前作品或任务重新取得引用，不将会话地址当作永久分享链接。

这里的内存回收只影响引用，不删除原片、预览、草稿、作品或导出。磁盘上的无引用派生文件仍由后续资产回收规则处理，与内存缓存分开。

高清显示另外使用本地 IndexedDB 保存可重建 JPEG，同一应用来源合计最多 64 项 / 256 MiB，按库 UUID / 源 hash / 档位 / 算法及解码版本分隔。它不在离线 CacheStorage，不替代图库权威清单。该缓存按 LRU 和字节删除自己的 JPEG 记录；设置可清理当前库，活跃图片 URL 与导出文件保持有效。具体身份核验、来源检查和限制见[分层显示与缓存](display-previews.md)。

## 检查范围

逻辑检查覆盖共享租约、活跃资源不被淘汰、条目与字节预算、排队取消、库切换、路径编码与拒绝原片／凭证／越界路径，以及本地响应的范围和不缓存行为。

浏览器检查以合成照片和本地文件建立 360 份草稿及 900 条历史结果，确认仅读元数据时零图片打开／零 Blob 创建；逐一访问后缓存仍有界，当前图片可继续读取。另检查缓存重置后导出字节不变、文件响应不进入 CacheStorage、相同 UUID 图库重开后的旧会话失效，以及禁用离线服务时图片和下载文件哈希正确。四种布局的交互与五万张瀑布流的选中、有界窗口回归继续保留；一万／五万条目的其余布局另作定向窗口检查。

以上是源码运行时与合成数据证据，真实设备峰值内存、不同 GPU 和安装包运行仍需发行阶段验证。
