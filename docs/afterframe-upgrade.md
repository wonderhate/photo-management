## 六点UI实施契约

1. 照片信息默认收纳右缘，鼠标停留同一张照片1000ms后出现；移开不关闭，展开后换图立即更新；右上角主动关闭。悬停与选中分离；提前离开、关闭、离开页面或打开模态取消计时；旧详情请求不得覆盖新图或重新打开抽屉。
2. 双击复用原照片浏览界面，保留全部信息和动作；单击选择，Enter/辅助技术/触摸保留可操作打开路径。仅删除手电筒模式及追踪，保留普通/极光/雪境/FilmTrain。
3. 默认启动保留现有摄影展示页面及策展，直接深链接和未保存保护继续有效。
4. 原左栏入口移到主顶栏附属图标栏，悬停1000ms显示文字；键盘焦点可读说明、aria-label与窄屏访问保留。
5. 内容区使用独立CSS光圈、遮幕及轻微缩放切页；550ms、连续切页320ms，最后点击生效；系统减少动态及页面隐藏取消动画。
6. 右上角摄影空间只返回现有启动展示页；不清除筛选/选中，不绕过未保存保护。

## 预览资源与调度验证

独立浏览器照片元数据不再调用`imageURL`读取两份图片文件；内部视图模型保存带图库ID的派生媒体引用，由`MediaImage/useMediaURL`在实际显示时解析。Windows/本机服务继续使用原HTTP图片地址。公开作品清单、原片读取、水彩和水印快照/导出协议保持原路径。

新增共享资源池，文件读取最多2个并发，当前主图、上下文图、缩略图、邻图按优先级排队。相同来源共享加载与URL；正在显示的引用不会因LRU淘汰而失效。闲置缓存受256项与96 MiB压缩文件字节预算约束，离屏缩略图释放引用，回到屏幕重新取得有效URL。已开始的File System Access读取不能强行中断，取消会废弃结果并保留并发计数至完成，防止快速切库突破读取上限或创建过期URL。

普通查看器在目标稳定300ms后只预读前后两张，主图使用高优先级，关闭、连续切图、进入胶片列车或页面隐藏会撤销旧预读。原生预读使用最多两张独立Image对象及浏览器低优先级提示；浏览器本地预读复用带租约的资源池。此实现不包含新的高清RAW解码器，不能把普通预览预读宣称为高清显影。

新增验证包括2000次资源访问的闲置预算、共享引用、在用资源保护、旧库请求失效、文件读取错误、新显式获取后重试、媒体路径白名单。浏览器实际检查了30次元数据读取不创建图片资源、280次压力淘汰后同一DOM图片恢复、在用图片URL持续可读、缺失派生缩略图使用原回退且原片哈希不变、备份重开、两侧邻图延迟预读及关闭后释放。相框/海报等旧资源链接仍沿用原生命周期，后续统一资产版本与回收时继续处理。

## 渐进登记、分批预览与导入中交互（2026-10-22）
