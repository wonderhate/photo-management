# 能力状态与运行适配

本说明对应融合开发分支。现有 Windows 桌面、本机网页与独立浏览器本地版继续使用自己的存储和执行引擎，原水印、水彩、人物与暗房流程保留。

设置中的「设备与功能状态」默认收起。展开或手动刷新才读取能力快照；检查不创建图像 Worker、不递归扫描模型目录、不加载或下载模型、不弹出授权窗口、不读取原片、不测试付费服务。状态失败局限于对应引擎；不返回原始异常、密钥或私人缓存路径。

| 状态 | 含义 |
| --- | --- |
| 可用 `available` | 当前执行条件已满足，仍需对每个实际输入进行原有校验 |
| 部分就绪 `degraded` | 可能缺少加载、授权或实际请求验证；不能单凭此状态判定能执行 |
| 不可用 `unavailable` | 当前环境不能执行，显示安装、授权或本机替代说明 |

快照另有 `runnable`、原因代码、执行位置、恢复动作及有限事实。例如已配置云服务为 `degraded / runnable=true`，仅表示可以显式发起请求；模型尚未加载为 `degraded / runnable=false`。面板是状态说明，现有后端和渲染器仍在真正执行前校验输入、来源、revision、凭证和权限，不依靠一次可能过时的快照放行。

## 当前检测范围

- 图库持久化、水印、本机暗房和 RAW 解码前提。
- 本地 Chinese-CLIP 的依赖、模型状态与实际已加载实例。检测不调用会递归计算缓存体积的旧状态方法。
- YuNet/SFace 的依赖、文件存在与已加载实例分别记录。文件存在仅为 cached，不能当作模型完整性或推理质量已验收。
- 千问水彩、标题及桌面批量水彩：缺密钥、密钥不可读、已配置但未验证连通性分别说明。配置成功不能证明账户权限、余额、服务可达或画质。
- 目录／照片选择器：系统依赖检测不打开窗口，真正选择时仍可能失败，原路径填写回退保留。独立浏览器仅在选择时请求目录权限，普通文件选择继续使用 HTML 文件输入。

RAW 状态检查 Worker、OffscreenCanvas、图片解码接口、WebAssembly 和跨源隔离。LibRaw 在实际打开 RAW 时才加载；面板不把环境支持当作所有相机格式已验证。普通照片与原标准预览不因此启动 RAW 解码。

独立浏览器读取当前图库句柄的既有权限，不请求新授权。浏览器水彩分别检查本会话密钥与中转地址，检查状态不建立 WebSocket，也不尝试连通。尚未适配的浏览器语义搜索、人物模型和批量水彩明确显示本机版替代说明。Windows 特例之外的剪贴板文件复制、拖出、系统定位和全套 Native bridge 仍待后续阶段，不在此批宣称完成。

## 适配入口

| 入口 | 已接入的实际路径 |
| --- | --- |
| `core/editor-adapter.ts` | 既有 Library / Render 适配：桌面 SQLite 工程／副本与浏览器本地清单，共用 v1 图像 Worker |
| `core/native-adapter.ts` | 目录与文件选择，保留系统选择器、本地目录授权、HTML 文件输入和原路径填写 |
| `core/inference-adapter.ts` | 本地模型状态／加载、人物模型下载与分析、千问标题／单张／桌面批量水彩 |
| `core/capability-adapter.ts` | 后端只读事实与浏览器图像能力组合；独立浏览器直接读取本地能力 |
| `/api/workspace/capabilities` | 本机服务的版本化能力快照，不包含渲染客户端特有的 Worker／隔离判断 |

推理适配器创建和状态读取都不执行推理。操作入口复用现有服务，不换模型、API 地址、密钥来源或原图片去元数据逻辑。云请求参数先复制为本次提交快照；独立浏览器仍经过已有逐次确认与会话内密钥流程，桌面继续使用原生成按钮披露、独立千问凭证及任务协议。取消和中断都不自动重发计费请求。

状态面板提供现有本地模型设置、人物页面、云服务页面和本机替代说明入口，原功能入口仍可访问。新添加的 VL/OCR、深度／分割、视频及更多系统功能将在实现时扩展契约；不把接口类型或模拟状态当作真实推理质量、硬件性能或发布安装验收。
