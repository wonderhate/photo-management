# 多图库选择与切换

此说明对应融合开发分支。原照片库、影集、人物、水印、暗房工程和水彩记录继续保存在各自图库中；选择已有图库不会复制当前库，也不会合并两库。

## 使用

在「设置 → 图库选择与最近图库」展开面板。可以粘贴图库目录，或用「选择目录」打开本机选择器。

- 已有图库：选择包含 `library.db` 的目录，点击「检查已有图库」，核对名称、照片记录数和图库身份，再选择该图库。
- 新图库：选择空目录并点击「在空目录新建图库」。程序先在自有临时目录创建完整空库，再发布到空目标目录。目标出现其它文件时不覆盖；新库拥有独立 UUID。
- 最近图库：保留最近 20 个目录及各库的导出／扫描目录配置。失效目录不会被当作新库创建；选择时重新验证。

选择后会显示待打开图库，当前仍使用原库。可取消选择；已明确创建的空库保留。已有目录、原片、历史导出、模型缓存和作品不会随取消选择被删除。

从桌面启动器运行的实例可点击「切换并重新打开」。程序先保存视图设置，检查正在保存的操作和后台任务，关闭新操作的入口，再结束旧服务并重新启动进程。原端口保留，主题、语言等原有站点设置继续生效；新进程从摄影空间启动，重新构建图库、任务、模型和媒体状态。若任务尚未安全结束，显示提示并继续使用当前图库，可在活动中心等待或取消后再试。

普通 `uvicorn` 或 `start.ps1` 启动的本机网页服务没有桌面重启控制，面板会说明需要用原启动方式重启；`start.ps1 -Restart` 继续有效。界面不会直接终止未知服务或改写已经加载的全局图库路径。独立浏览器版沿用自己的同页关闭／打开流程，见 [图库视图设置](workspace-preferences.md)。

## 设置、迁移与原片

全局配置保存最近图库及待打开目录，不保存原片、模型权重或凭证。图库布局、排序和作品视图随图库数据库保存。首次选择另一个未登记图库时，导出使用其 `exports/`，自动扫描目录为空；再次打开已登记的图库时恢复该库自己的导出、历史导出和扫描配置。模型缓存沿用当前配置。独立千问凭证仍位于各库，环境凭证仍按原有明确配置规则生效，不读取 OpenAI 凭证。

旧「照片库与存储」入口仍负责复制迁库及修改模型／导出目录。它与待切换图库互斥，避免把“打开已有库”和“复制到空库”混成一个操作。选择已有库会只读检查格式、版本和身份；旧库真正打开时继续使用原有备份与幂等迁移机制，不引入 AfterFrame 数据格式。

显式 `PHOTO_DATA_DIR` 启动的实例禁止从此处切库。显式导出目录也不被选择覆盖。配置仍使用 `PHOTO_LIBRARY_CONFIG` 或原有个人配置位置，遵守旧配置兼容回退。

## 会话和失败处理

每次服务进程拥有新会话 ID。本机前端从响应头绑定图库与会话，后续元数据、文件上传、预览及原片请求携带绑定，返回的媒体／导出链接也带会话参数。旧网页即使仍开着，也不能在新服务接替端口后将旧设置写入新库。即使回到相同 UUID 的原库或恢复副本，旧会话仍被拒绝；应刷新旧网页后继续。

切换确认时再次核对本次选择标识与目标图库身份。目录丢失、版本太新、不可读或身份被替换时保留原启动选择和待处理信息，显示失败原因；不会将缺失图库静默当作空库。配置写入沿用原子替换。旧服务未安全结束时不会启动另一图库。

任务和已完成作品仍按原库保存，不随切换搬移、删除或自动重发。关闭与恢复中的云请求沿用任务服务的提交边界、不确定状态和无自动计费重试规则。

## 验证范围

合成测试覆盖只读检查、现有库不被复制、新建空库、目标被占用、环境锁、过期窗口、迁移互斥、目标被替换／版本过新／损坏、保存失败、任务及保存屏障，以及原片哈希。

实际受管理启动器在隔离目录完成 A → B → A 进程重开，验证稳定图库 UUID、新会话、照片与已完成任务隔离、浏览偏好恢复、每库千问凭证隔离，以及旧会话写入和媒体参数被拒绝。界面另验证中文暗色宽屏／英文浅色窄屏的检查、选择、取消、被任务阻止后重试，以及启动锁定。

这些检查没有使用私人图库、下载模型、调用真实付费生成或替换已安装程序。受管理进程测试使用启动器的无窗口诊断模式；新安装包与真实 WebView 窗口的发行验收仍归发布阶段。
