# Windows 2.7.3 与首次使用优化 · 2026-10-28

这一轮按六项体验审查改进入口、首次体验、导航、公开内容、下载决策与地图空态。共用工作区在 Windows 和浏览器中同步；保留全站三分之一指针光照半径、跳过建库、缩放自动高清与减少动态效果。

## 具体改动

1. 摄影展示、浏览器工具、Windows 下载各有清晰入口，明确浏览器条件与本地保存方式。
2. 浏览器可直接用程序绘制的示例调色、装裱、下载 PNG，不读取已有图库或请求目录权限。建库后继续先前的暗房打开操作。
3. 工作区常用入口显示文字，按照片、整理、创作组织；小屏保留三个主要入口，其余收进“更多”，支持键盘退出和焦点恢复。
4. 六张精选作品采用基于画面的客观说明，增加两个主题系列；三步产品展示使用实际渲染器生成的示例，不编造拍摄地点或作者经历。
5. 下载首屏提供推荐安装器、版本、系统、大小与公开试用状态；说明浏览器与桌面能力区别，历史 Linux 预览折叠显示。
6. 地图在空图库、筛选无结果、缺少坐标和视野无照片时给出具体操作；主要模式为地球／地图，服务配置放入进阶设置；坐标校验区分地点名称与真实坐标。
