# 全界面液态玻璃与动效

本次为用户于 2026-10-27 新提出的全界面材质统一需求，独立于原有 99 项功能验收登记；不重开、更名或修改已有 AF／PC 条目的状态。已有未提交功能与安装验收待办继续保留。

## 覆盖范围

Windows 与本机网页版共用 `frontend/src/liquid-glass.css`，由入口设置 `data-material="liquid-glass"`。深浅主题继续使用原有背景、文字与品牌色，玻璃参数由统一的 `--glass-*` 变量管理。

| 区域 | 共用材质 |
| --- | --- |
| 顶栏、附属图标导航、侧栏和提示 | 背景透光、柔和高光边缘、统一选中态 |
| 图库与四种布局、影集、智能影集、人物、视频 | 工具区、卡片边框、照片说明与上下文菜单 |
| 时间线、地点、统计、报告 | 导航面板、筛选、统计和图表外框 |
| 设置、图库选择、模型、目录与能力信息 | 设置面板、输入框、选择框和执行反馈 |
| 暗房、LUT、文字／图层、相框、切图、拼图 | 编辑工具栏、参数面板、工程和输出信息 |
| 水印、水彩、AI 创作与标注 | 控制面板、结果卡片、任务范围和状态 |
| 照片悬停信息、原查看器详细信息 | 同一材质，保持原有完整内容和打开规则 |
| 弹窗、最近操作、任务中心、命令菜单 | 更稳定的柔雾背景和统一浮层边缘 |
| 浏览器本地图库欢迎页与已有展示页 | 共用导航、控件、照片信息和浮层材质 |

大面积功能面板使用背景采样；大量照片卡片使用相同的半透明填充和高光边缘，避免对每张照片重复进行背景模糊。嵌套行和按钮共用外层材质，避免重复模糊。照片、画布、直方图、颜色样本和导出像素维持原有显示语义。

## 动效

| 触发 | 反馈 |
| --- | --- |
| 鼠标移到功能栏或控件 | 局部柔光跟随指针，像光由玻璃背后透出；同时作用于最近功能面板和当前控件 |
| 同栏切换按钮 | 保留外层光感，清除上个按钮的局部光点 |
| 鼠标离开、滚动、窗口失焦、页面隐藏 | 取消排队的光点更新，清除旧坐标与按压状态 |
| 按下控件 | 内侧阴影与透光发生轻微变化；保留几何手柄和地图原有定位 |
| 键盘聚焦 | 中央静态照明与原焦点轮廓；不要求鼠标悬停 |
| 弹窗、菜单、照片信息栏出现 | 共用 240ms 的轻微位移与透明度过渡；动画结束后释放位移状态 |
| 页面切换 | 沿用已有 550ms／连续切换 320ms 光圈逻辑与最后请求生效规则 |

照片查看器的外框保持静止，避免入场位移改变精确缩放、拖动和胶片全屏坐标；原有展映内部动效继续使用。照片详情浮层采用更稳定的柔雾背景与清楚的文字色，保持复杂照片背景上的参数可读性。

`glass-interaction.ts` 使用委托事件和单个待执行 RAF。每次移动最多更新一个容器与一个安全控件，不使用 React 状态刷新，不注册逐照片的鼠标监听，也不添加常驻循环动画。照片卡片、色板、选片星级、地图点、拼图槽位和各类几何手柄均从追光机制中排除。

`prefers-reduced-motion` 禁用追光和新入场动效；键盘仍保留清楚的静态焦点。高对比或减少透明度偏好使用实色背景，并停止背景采样；强制颜色模式使用系统颜色。不支持背景模糊时也回退为实色，操作和布局保持可用。

## 行为与数据边界

悬停照片 1000ms 才显示信息、移开后保持、单击选择、双击浏览、图标提示延迟、未保存保护和减少动态效果的规则继续生效。玻璃运行时不阻止事件、不改变焦点、不触发 API，不接触原片、导出、数据库、凭证或模型。

照片信息里的评分和颜色标签说明移除固定的深色专用文字颜色，改为主题变量，保证暖白主题同样清楚。
