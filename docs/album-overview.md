# 影集总览：封面、日期、最近照片与批量整理

本功能位于 AfterFrame 融合开发分支，尚未发行。适用于 Windows / 本机服务与独立本地网页版。普通影集、人物影集、语义影集和条件集合沿用各自成员规则。

## 使用

- 在影集页切换「卡片」「表格」，展示方式随当前图库保存，与已有搜索、自定义顺序及排序设置共存。卡片每页最多 24 个，表格每页最多 50 行，避免一次挂载整个影集库的图片。
- 自动封面从当前成员顺序选取最多四张照片。手动设置的单张封面优先；即使照片记录失效，也显示「手动封面不可用」，不会悄悄改用其他照片。可主动点击「恢复自动封面」。浏览器旧版本没有标记封面的来源，因此升级时把已有非空封面按手动封面保护。
- 日期跨度使用当前成员的拍摄日期；没有日期的照片单独计数。普通 / 人物 / 语义影集显示最近加入的日期。没有历史记录时显示「未知」，不从影集更新时间或照片导入时间推造加入时间。
- 点击「最近加入」查看分页照片；双击照片进入原有照片浏览界面。新成员记录加入时间，保留成员、改名和调序不重置时间；移出后重新加入才记录新的时间。旧关系保持未知时间并排在末尾。
- 条件集合显示「最近导入匹配」，按当前匹配照片的导入时间排序。它是动态查询，不记录虚构的加入时间。
- 勾选影集或「选择本页影集」，点击「删除所选影集」并确认。仅删除所选影集及其成员关系；照片记录、原片、人物、人脸与作品草稿保留。搜索变化会移除已隐藏项的选择，避免误删不可见影集；切页保留当前搜索范围内的选择。

所有操作仍支持中英文与明暗主题。减少动态设置下封面无缩放过渡。表格在窄屏内横向滚动，不撑宽整个页面。

## 数据与兼容

下述为 AF17 引入的结构；后续[评分来源保护](xmp-rating.md)以及[独立选片标记](photo-flags.md)以及[人工描述与标签来源](photo-annotations.md)及[多选筛选](photo-facets.md)与[本地人物模型保护](face-model-spaces.md)及[人物整理](person-management.md)及[连续切图保存基础](seamless-split.md)使当前格式更新为 SQLite 21 / manifest 17，原有影集数据继续保留。

桌面 SQLite schema **6** 为 `album_photos` 增加可空 `added_at`。升级前沿用 SQLite 备份，迁移事务失败回滚；原有关系为 NULL，新关系才使用当前时间。重新审阅语义候选时按成员差异更新，保留仍在影集的成员加入时间、手动位置和未显式替换的相似度分数。库复制 / 合并继续使用既有关系复制机制。

浏览器 manifest **5** 增加可选 `member_added_at` 与 `cover_mode`，以及影集列表的 `view` 偏好。可读取旧 1–4 格式；首次成功写入前，将旧 `library.json` 的完整原始字节保存为 `library.before-overview-v5-*.json`。备份失败不会写新清单，旧时间不会自动补齐。未知未来版本、把新增字段标成旧格式、无效日历日期或不属于影集的加入时间项均拒绝覆盖。

桌面封面 / 日期汇总按既有拍摄分组与首选照片查询，RAW + JPEG 不重复计数。普通影集汇总批量执行 SQL，封面每个最多返回四个 ID，不加载整库 EXIF；最近照片只加载当前页。条件集合复用现有 PhotoQuery，成员随元数据变化。浏览器基于当前元数据快照与照片 ID 索引计算，汇总和最近列表本身不读取原图；图片按需交给既有媒体服务。

`POST /api/albums/batch-delete`（浏览器对应本地适配器）接受 1–1000 个唯一影集 ID；请求中任意影集已不存在时整体拒绝，避免部分删除。删除后同步清理列表的对应编排 ID。与所有库修改一样，浏览器保留 revision / 会话代次检查，桌面保留图库绑定校验。

## 验证范围

合成库检查覆盖：迁移备份、失败回滚、未知历史、手动 / 失效封面、RAW/JPEG 计数、分页及语义成员重审、批量删除原子性、人物 / 草稿关系和源文件 SHA-256。浏览器另验证备份失败保持旧字节、未来格式拒写、元数据查询无文件读取、删照片时移除对应时间项。

界面在中文深色宽屏与英文浅色窄屏执行四图 / 手动封面、恢复自动、最近照片双击、表格恢复、搜索后批量删除和原片保留。完整测试结果记入[融合实施记录](afterframe-upgrade.md)，此功能通过不代表全部 99 项升级已经完成。
