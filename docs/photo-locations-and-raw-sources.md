# 地点、Discover 与人工 RAW 来源

本文对应固定十任务批次中的 AF06、AF64、AF65、AF66，以及同批的 AF67、AF68、AF69、PC18、PC21、PC22。十项完整实现后统一验证，2026-10-26 已完成源码运行时验收。测试范围与限制见文末及 [实施记录](afterframe-upgrade.md)。

## 地点与地图

照片信息区的“拍摄地点”允许填写国家或地区、城市、地点名称，以及可选的经纬度和精度。人工地点以单独记录保存，与照片 SHA-256 绑定；原始 EXIF 和原文件不修改。只填写地点名称时，不混用旧 GPS 作为新地点的坐标。清除人工覆写回落到原始 GPS，撤销恢复上一次地点状态，最多保留 20 步历史。跨窗口写入检查记录版本。

“拍摄地点”导航页按需加载。原有照片浏览器继续负责打开单张照片。地图采用随包发布的 Natural Earth 陆地轮廓，不请求在线瓦片、逆地理编码或地名 API。底图为自然陆地，不包含行政边界；来源、版本和下载文件哈希见 `frontend/public/licenses/natural-earth-land.json`，转换脚本为 `frontend/scripts/prepare-map-land.py`。

地图支持指针拖动、方向键和按钮平移、缩放、跨日界线视窗、国家和城市筛选、无坐标入口与当前范围照片下钻。桌面采用事务内触发器维护的 SQLite R*Tree；浏览器采用可从清单重建的网格空间索引。筛选最终检查精确坐标，避免 R*Tree 浮点边界扩张导致误包含。

地图按视窗聚合全部符合条件的记录，只返回最多 300 个聚合点，并在超过上限时明确显示总数、聚合数和截断说明。计数和照片下钻使用同一个范围与拍摄/文件口径。空间索引可重建，不是原始地点的唯一存储。

## Discover

保留现有展示首页及手选 12 张作品，在下方增加可折叠的回忆、人物、地点和影集区。展开状态使用现有图库偏好持久化。折叠时不拉取建议，不启动人物分析。

回忆优先列出往年今日，其余位置使用拍摄月份；无 GPS 不影响回忆。日期使用相机记录的日历日期，无效日期单独计数，不猜测日期。人物读取已有本机分组，纯网页版明确说明当前未启用人物识别。地点名称来自人工填写；未命名的 GPS 照片仍可通过地图查看。影集、人物和回忆卡片使用拍摄口径下钻。

## 外部 RAW 来源

在非 RAW 照片的信息区展开“外部 RAW 来源”，显式选择目录后登记 RAW 的哈希和拍摄元数据。登记任务可取消，已完成条目保留；重复内容按哈希合并，重新登记可更新同内容的外部路径。

登记不导入额外照片、不创建 CaptureGroup，也不会写入 RAW 或导出成片。候选同时列出名称、时间和机型线索及冲突；所有候选都必须逐一人工确认。用户勾选核对声明后才保存关联，关联保存前校验成片和 RAW 的当前哈希，并检查并发版本。解除关联只修改图库记录。

人工关联独立于原来的 RAW/JPEG 分组。旧照片 ID、影集关系、草稿和拍摄计数不由候选排名重写。来源路径是私人图库信息，不得进入公开作品包。

## 持久化

本批格式为 Native schema 26、Browser manifest 22。地点、RAW 来源和人工关联分别保存，复制及合并保留其记录；合并发生相同照片冲突时，以目标库已有人工决定为准。Browser 首次写入新版格式前保留旧清单原字节备份。

统一回归覆盖日界线和边界坐标、十万点聚合、无 GPS/无日期、人工清除与撤销、RAW 候选冲突及人工确认、并发版本、原片哈希、旧库升级与失败回滚。地图中英文、深浅主题、1440px/390px 与减少动态效果均纳入浏览器验收。


## 同批生命周期与派生资源

照片移出后保留完整记录与关联，可在设置的移出记录列表恢复。原片与托管原始副本不删除。现有水印草稿和暗房工程仍通过保留的来源读取原片；普通照片列表、地图和人物封面排除已移出的记录。

桌面扫描合并 Windows 文件变化提示，并每五分钟补扫；浏览器需在设置中逐个启用原片目录，只在页面活跃且已有读取权限时扫描。RAW 来源登记不自动启用照片扫描。已移出记录的内容和路径不自动重新导入。相同路径出现不同内容时保留旧记录，要求用户明确处理；重新定位只接受 SHA-256 相同的来源，并保留照片 ID 和影集关系。

照片信息中的来源图分开显示拍摄分组、人工 RAW 关联、编辑来源和渲染副本，包含水彩、水印、拼图与切图关系。每次最多显示 80 个记录和六层关系，截断时明确提示，可点击记录继续查看。普通暗房副本也保存来源工程版本与配方快照。

设置中的派生文件回收列出未引用的旧水彩版本、水印预览、暗房副本、拼图成品与切图输出，保护在用版本、登记为原片的文件及编辑来源。文件暂存到图库的 recycle 目录，先写恢复日志，再移动或复制；可恢复，不立即释放磁盘空间。操作期间需要后台任务与其他保存结束。当前没有永久清空回收文件的操作；桌面优先使用无覆盖硬链接；Windows 不支持硬链接的文件系统使用同盘无覆盖重命名。中断后的完整来源和恢复日志保留，目标路径冲突时拒绝覆盖。

公开选片增加水彩、拼图成品与切图面板，仍默认不选任何作品，不自动公开关联的照片或工程。复制/备份纳入回收日志与新资源；桌面迁移在目标盘暂存后发布，浏览器最后写入清单作为完成标志。模型和外部原片保持独立位置。

## 验收边界

本批使用隔离的合成图库。覆盖了复制失败回滚、回收中断、目标冲突、同内容重定位、扫描权限和断开状态；迁移中断通过测试注入写入失败验证，没有宣称已执行真实跨物理磁盘拔盘实验。Web 离线重开与重授权使用合成目录句柄，不能替代所有浏览器或移动设备的目录权限兼容性测试。安装包与真实照片云端生成不在本批验收中。

统一回归还修复了移出记录在文字索引中残留、旧水印草稿重定位归档来源失败、无效地点响应影响查看器及公开水彩选片预览来源错误。已有草稿、照片 ID 与归档关系继续保留；原片哈希检查通过。
