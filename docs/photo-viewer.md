# 照片查看与白底校样（融合开发分支）

双击图库照片继续打开原有浏览界面。普通、极光、雪境和胶片列车保留；手电筒模式按六点 UI 修订移除。收藏、照片信息、编辑入口、自动播放、全屏和照片导航保持。

图库滚动过程中仍可点击选择和双击打开照片。虚拟列表保留按需渲染，但不再在滚动结束前屏蔽内部照片的点击；网格、紧凑、等高和瀑布流均检查两次实际按下后打开同一张照片。人物分组区域打开的大图只在当前人物照片间翻页；实时人物范围与已保存影集快照的区别见[实时人物照片](live-person-photos.md)。

## 缩放和移动

普通查看器支持适应窗口、输入 1%–800%、加减档位、100% 和鼠标滚轮缩放。滚轮以指针处为中心；放大到超过窗口后可拖动，并限制移动边界。双击图片在适应窗口与 100% 之间切换。缩放状态留在当前照片内，切换照片恢复适应窗口，避免下一张从局部开始。

100% 指当前预览的一个像素对应一个 CSS 显示像素，不表示 RAW 原始像素或屏幕物理像素。下方清晰度选择仍独立控制标准 / 4096 / 6144 预览，较高档位沿用已有的当前照片按需解码、源哈希核验和取消机制。高清加载后保持当前关注区域，不替换编辑器或导出的源。

触摸在适应窗口时仍支持横滑切图，放大后拖动用于查看图片局部，避免同一次操作切换照片。这是本机网页的输入支持，不恢复已退役的移动客户端。

## 白底与工具栏

白底校样临时使用纯白背景并隐藏极光、雪花等展映效果；再次关闭恢复既有展映设置。它不修改图片、颜色管理、工程或导出，也不提供打印机 ICC 软打样。白底选择在本次查看器中切换照片时保留，关闭查看器后复原。胶片列车继续使用原有展示和边缘工具。

浮动工具在闲置 1.8 秒后收合，移动鼠标或聚焦工具会唤回；“固定查看工具”可保持显示。键盘正在操作或输入缩放时不隐藏。系统启用减少动态效果时工具保持静态显示，不新增布局跳动。

## 键盘

| 默认按键 | 操作 |
| --- | --- |
| `+` / `-` | 放大 / 缩小 |
| `0` | 适应窗口 |
| `Z` | 当前预览 100% |
| `B` | 白底开关 |
| 左 / 右方向键 | 上 / 下一张，保留原可重绑设置 |
| 胶片条聚焦时 `Home` / `End` | 第一 / 最后一张，并跟随焦点 |
| `Esc` | 关闭并恢复打开前的焦点 |

新增命令仅作用于照片查看器，可在设置中重绑。已有自定义绑定优先于新增默认按键；发生冲突时新默认命令显示“未绑定”。输入框、快捷键录制和其他模态沿用保护规则。胶片条仍只渲染邻近的最多 17 张，不为大库展开所有图片。
