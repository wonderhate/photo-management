# Windows 与 Android 同步网页版 UI

独立分支：`codex/windows-android-web-ui-sync`。基于 Windows 配对改动 `9a88820`，合入网页版 `origin/main` 的 `98a95d7`，保留完整电脑地址、八位配对码和原有远程访问协议。

Windows 2.2.3 使用与网页版相同的前端产物，移除旧音乐布局样式对新主题的覆盖。首页、影集、照片行布局、沉浸浏览和可选展映效果共用现有实现，浅色模式继续使用暖白分区与金色强调，已有主题偏好保留。

Android 2.0.1（versionCode 3）将本地连接页改为相同的色彩、字形、留白与表单层次。手机照片库的导航、卡片、输入框和创作页面使用共用主题变量，取消旧红色强调和胶囊样式。原有五栏导航、触摸浏览、索引缓存和显式相册导出保留。

连接页增加中英文切换，错误提示随语言变化；首次进入照片库时携带所选语言并立即移除 URL 语言参数，避免覆盖用户之后在照片库修改的偏好。原生桥只在本地连接页启用，网络页面不暴露桥接口。

Android 连接页与启动图标复用 `frontend/public/icon-512.png`，启动器使用原生自适应图标及单色图形。状态栏、导航栏和窗口背景采用暖白色。

安装包：`releases/PhotoCollection-Setup-2.2.3-x64.exe`、`releases/PhotoCollection-Windows.zip`、`releases/PhotoCollection-Android.apk`。验证使用隔离的合成照片库与专用 API 35 模拟器。

- 实际 Windows EXE 的 16 项浏览器检查通过；原生 WebView 加载检查成功。
- Windows 实际 EXE 的版本、构建身份、网页版图标、配对、照片编辑、电脑草稿、导出、图片禁止缓存、源文件哈希、访问撤销和 ZIP 私人文件排除检查通过。

- 正式 Android APK 在专用 API 35 模拟器中通过中英文连接页、语言带入与后续切换、配对、五栏导航、收藏、电脑草稿、图片预览、受限索引和手机相册导出检查。

## 2026-10-12 极光背景修正

Windows 2.2.5 将极光背景层向四周扩大 `20vmax`，让旋转和平移时的矩形边缘始终处于照片显示区域之外。保留原有九秒动画、颜色、照片本身的尺寸和减少动态效果的设置。

新增几何回归检查，覆盖 1920 × 540 宽屏和 900 × 1200 竖屏，在动画的五个阶段确认背景覆盖全部四角。旧 Windows 2.2.4 包可复现边缘露出，修正后的共享前端通过检查。

Windows 2.2.6 修复照片详情与批量编辑的颜色标签被通用按钮背景覆盖的问题。四种标签改为对应颜色的空心圆环，选中时加粗圆环并显示中心圆点，再次点击可清除。增加中英文名称和按下状态，浅色主题的黄色圆环加深以提高辨识度。

Windows 2.2.7 与网页版启动默认打开「摄影空间」，明确指定照片、影集、水印等页面的链接仍打开对应页面。Android 2.0.2（versionCode 4）配对或重新连接后也进入摄影空间，保留语言选择与既有签名。独立分支：`codex/startup-photography-space`。

Windows 2.2.8 与网页版、Android 远程页面共用「艺术字署名」设置。水印工坊可选择原版 wonder 连笔、细线手写、毛笔笔触、经典花体或普通文字；字体样式可修改署名内容，原版图片保留固定字样。署名显示于相框信息栏或沉浸光感页脚，预览、草稿恢复、单张与批量导出使用同一套本地素材。三种字体及各自 OFL 许可随 Windows 包内置。独立分支：`codex/signature-art-styles`。

Windows 2.2.9 提供更新后的手机页面：照片详情只保留普通浏览，移除播放展映、展映模式、摄影氛围和全屏按钮，「我的」页面移除键盘快捷键设置。保持原有页面尺寸、照片信息、收藏、滑动和上下张切换、水印流程。Android 2.0.2 连接更新后的电脑服务即可使用新页面，无需重装 APK。窄窗口或手机远程页面始终使用普通模式，切换为手机布局时清理旧展映状态和自动播放计时。桌面布局保留这些功能。独立分支：`codex/mobile-standard-view`。

Windows 2.2.10 将已有对应影集的人物卡片改为「打开人物影集」。新建时保存人物关联，改名、刷新和调整影集成员后仍能打开。旧影集通过完整拍摄集合兼容识别，只考虑人物创建后的普通影集；存在多个对应影集时让用户选择。没有对应影集时保留原有新建、确认分组和空分组校验。数据库新增关联列前自动备份，删除人物时保留影集和原图。网页及 Android 远程页面同步使用此入口。独立分支：`codex/person-album-open`。

Windows 2.2.11 新增中文毛笔、中文行书、中文草书、中文手写四种艺术字署名，分别内置 Ma Shan Zheng、Zhi Mang Xing、Liu Jian Mao Cao、Long Cang 的原始字体文件与 OFL 许可。以 `chinese-signature-fonts.md` 的书法风格为参考，未将其中需要额外授权的商业字体打包。署名内容可编辑，常用中文及中英文混排使用所选字体；只有超出字库覆盖的字使用系统字体，其他字保留所选书法风格。相框和沉浸水印的预览、草稿恢复、导出共用本地字体；网页及 Android 远程界面同步支持，英文标签和说明也已补齐。独立分支：`codex/chinese-art-signatures`。

Windows 2.2.12 将所有署名风格移至水印信息栏的水平和垂直中心。现代信息条的署名位于厂商图标左侧，拍摄信息分别排列于两侧；沉浸光感取消中间分隔线，署名居于水印框正中间。普通文字署名也使用同一位置。旧草稿预览在原图可用时自动更新，保留草稿设置、版本记录和原图；原图离线时保留已有预览。网页与 Android 远程页面共用渲染结果。独立分支：`codex/signature-center`。
