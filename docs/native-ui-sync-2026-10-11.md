# Windows 与网页版 UI

当前 2.4.0 仅提供 Windows 和本机网页版，已移除手机客户端、配对、远程访问、公网地址登记与手机相册桥接。独立分支：`codex/remove-android-remote`。桌面服务仅监听 `127.0.0.1`，网页版继续保留响应式布局。

保留摄影空间、影集、人物影集入口、自定义照片库和存储目录、中英文界面、浅色分区、网页版图标与原图保护。

水印工坊保留中英文艺术字署名与本地字体。署名居于水印信息栏中心：现代信息条位于厂商图标左侧，沉浸光感取消中间分隔线；草稿、预览和导出使用相同渲染位置。

展映保留极光背景扩大防止边缘露出，以及胶片列车。胶片列车使用连续大图、原始比例、全屏与边缘悬浮控制，可暂停、调速、循环切换，退出时恢复普通浏览。窄屏网页保留普通浏览与触摸切换。

安装包：`releases/PhotoCollection-Setup-2.4.0-x64.exe` 与 `releases/PhotoCollection-Windows.zip`。私人照片库不用于检查；安装升级保留已有配置与照片。
