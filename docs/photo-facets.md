# 多选、排除与自定义筛选栏（融合开发分支）

照片页点击「筛选」，展开常用筛选栏。相机、镜头、标签、评分等可以同时选择多项；不同项目之间共同限定结果。旧文件类型入口继续提供 RAW、配对、仅 RAW / JPEG 等既有选择。

## 操作

- 点击筛选项目，在弹窗中勾选多个值。同一项目通常匹配任一选中值；标签可切换「任一标签 / 全部标签」。
- 切换「排除」反转该项目的完整条件。比如排除某机型会保留没有机型记录的照片；若也勾选「未设置」，则连同缺失记录一起排除。
- 数值可直接选值或设范围，范围可选择是否包含边界。评分 0 与「未评分」分开；焦距、ISO、光圈和快门秒数沿用原始数值。
- 拍摄 / 导入日期支持范围。结束日期默认包括当天最后一秒及其小数部分；不包含边界时按该日零点作为严格上界。拍摄墙钟时间不自动换时区。
- 「当前描述」「人工描述」「AI 原始描述」「识别文字」支持文字包含，沿用[全文搜索](text-search.md)的人工作主和字面匹配规则。
- 点击「清除此项」只移除该栏的临时条件；影集本身的成员或规则继续保留。

画幅根据已保存的显示宽高分为横幅、竖幅、方形，可同时选多种。缺少有效宽高时按未设置处理，不拿照片的 EXIF 方向数字当作画幅。

## 选项数量

每个选项后的数量遵循当前范围与其他项目的条件，暂时忽略正在查看的这一项。影集成员、条件集合本身的规则以及显式基础 QueryAST 始终限制范围。这样可以在已经选择某机型后继续看到其他可选机型。

已选但在其他条件下没有结果的值仍保留，显示 0；可以直接取消，不因隐藏选项而无法解除条件。搜索选项、继续加载和缺失值数量均按相同范围计算。本机服务在数据库中计数并分页，只返回当前页选项；独立网页在本地元数据上计算，不读取原片。

图库默认按首选照片的拍摄口径计数。本机计数接口也支持文件口径；独立网页沿用当前逐文件图库能力，不宣称已具有 RAW / JPEG 分组。

## 自定义与保存

「自定义筛选栏」选择常用项目，按图库保存显示偏好。隐藏但已生效的项目仍显示，避免看不见的条件限制结果。筛选值是当前浏览状态，不保存为个人常用机型或泄露到公开作品；需要长期保存的规则使用条件集合。

可选项目由当前已实现的数据决定，包括器材、曝光、日期、标签、文件格式、画幅、收藏、RAW 标志、评分、选片、颜色标签与描述 / 识别文字。主色、地点等后续功能完成后再接入，不把尚未具备的数据伪装成可用选项。

Windows 偏好保存在现有 `library_profile.preferences.facets`，独立网页保存在可选 `facet_preferences`；只保存隐藏项目列表。沿用图库身份、事务合并、浏览器会话 / 修订保护和待保存恢复；重开同一 UUID 后，旧适配器仍不能保存。复制迁库保留偏好，合并保留目标图库的选择。

## 兼容与边界

现有本机查询参数及相机 / 镜头别名保留；新 `facets` 参数为有界、版本化结构，编译为原有 QueryAST，与旧条件取交集。编辑某个项目时会移除它对应的旧单值 / 范围参数，再保存新的多选条件，保留其他条件与影集范围。范围、缺失、否定在两端遵循共同向量，不接受任意 SQL 或路径字段。

[当前存储格式](seamless-split.md)为 SQLite schema **16** / browser manifest **11**。新增画幅查询字段需要版本门槛保护；SQLite 升级先备份，失败保持旧版并可重复执行。浏览器读取旧 1–10；从低于 10 的格式首次写入时，把旧清单完整字节保存在 `library.before-facets-v10-*.json`，备份失败不发布。未来格式、旧格式冒用画幅规则或新偏好、无效 / 重复隐藏项均拒绝写入。

本功能使用现有配色，不上传照片、不调用模型、不写原片。验证包含两端共同查询向量、关联计数、影集与固定规则范围、分页、日期边界、零分 / NULL、升级失败、旧写入者隔离和合成原片 SHA-256；完整结果见[融合实施记录](afterframe-upgrade.md)。更大的浏览器标签索引和性能测量继续由后续条目验收。
